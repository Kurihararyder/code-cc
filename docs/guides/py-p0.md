## 三、單元 1–2：輸入輸出、運算與條件

### 輸入輸出
| 寫法 | 說明 |
| --- | --- |
| `input()` | 讀一行，**回傳字串**（不含換行） |
| `a, b = map(int, input().split())` | 一行兩個整數 |
| `print(a, b, sep="-", end="")` | 用 `sep` 分隔、用 `end` 結尾（預設換行） |
| `print(f"{x:.2f}")` | 格式化：小數 2 位 |

### 運算子（和 C／C++ 最不同的地方）
| 運算 | 結果 | 說明 |
| --- | --- | --- |
| `7 / 2` | `3.5` | `/` 永遠是浮點除法 |
| `7 // 2`、`-7 // 2` | `3`、`-4` | `//` **向下取整**（往負無限大） |
| `-7 % 3` | `2` | `%` 的結果和除數同號：`a == (a//b)*b + a%b` |
| `2 ** 10` | `1024` | 次方；整數**不會溢位**（`2**100` 正常） |
| `divmod(17, 5)` | `(3, 2)` | 商與餘數 |
| `round(2.5)` | `2` | 四捨六入五成雙（銀行家捨入） |

- 浮點誤差：`0.1 + 0.2 == 0.3` 是 `False`；比較浮點數用 `abs(a-b) < 1e-9`。
- `3 == 3.0` 是 `True`；`"5" * 3` 是 `"555"`；`True` 等於 1。
- 比較可以連寫：`1 < x < 10`。

### 條件
- 值為**假**的：`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()`、`None`、`False`；其餘為真。
- `and`／`or` 回傳**被決定結果的那個運算元**，不是布林值：`0 or "a"` → `"a"`；`"" and 5` → `""`。
- `if / elif / else`，**縮排就是語法**；比較是否為 None 用 `is None`。

## 四、單元 3：迴圈

- `range(a, b, step)` 是**半開區間** [a, b)：`range(5, 0, -2)` → 5, 3, 1；長度 `len(range(2, 10, 3))` = 3（2、5、8）。
- `for i in range(3): pass` 結束後 `i` 還在，值是 **2**（最後一次的值）。
- `break` 離開迴圈、`continue` 跳到下一輪；迴圈的 `else` 區塊**只在沒有被 break 時**執行。
- `enumerate(seq, start)` 同時給索引和值；`zip(a, b)` 以**最短**的為準。
- `sum(range(1, 101))` = 5050（高斯求和 n(n+1)/2）。
- 兩層迴圈各跑 n 次 → n² 次運算；n = 10⁵ 時 Python 就太慢了（約 10⁷–10⁸ 次簡單運算是上限）。

## 五、單元 4：字串與 list

### 切片（slice）`s[start:stop:step]`
| 寫法 | 說明 |
| --- | --- |
| `s[1:4]` | 索引 1、2、3（不含 4） |
| `s[-2:]` | 最後兩個 |
| `s[::-1]` | 反轉 |

- 字串**不可變**：`s[0] = "x"` 會 `TypeError`；要改就建新字串。
- `"a,b,,c".split(",")` → `['a', 'b', '', 'c']`（保留空字串）；`" a  b ".split()` → `['a', 'b']`（不帶參數會吃掉所有空白）。
- `",".join(list)` 把字串清單接起來；`s.find(x)` 找不到回 -1，`s.index(x)` 找不到丟 `ValueError`。

### list
- list **可變**。`b = a` 是**同一個物件的別名**；複製用 `a[:]` 或 `a.copy()`。
- `[[0]*2]*2` 兩列是**同一個**內層 list；正確：`[[0]*2 for _ in range(2)]`。
- `a.sort()` **就地排序、回傳 None**；`sorted(a)` 回傳新 list。
- `a.append(x)`、`a.pop()`（最後一個）、`x in a`（O(n)）。
- 字串比較是**字典序**：`max(["10", "9"])` 是 `"9"`；要數字比較先 `int()`。
- 索引超出範圍：`[1,2,3][5]` → `IndexError`。

## 六、單元 5：set、dict 與函式

### set 與 dict
| 結構 | 重點 |
| --- | --- |
| `set` | 無序、不重複；`x in s` 平均 O(1)；`{1,2} & {2,3}` = `{2}`（交集），`|` 聯集，`-` 差集 |
| `dict` | 鍵值對；**依插入順序**走訪；`d.get(k, 0)` 不存在給預設；`d.setdefault(k, [])`；鍵必須可雜湊（list 不行，tuple 可以） |
| 計數 | `d[k] = d.get(k, 0) + 1` 或 `collections.Counter` |

### 函式
- 沒有 `return` 就回傳 `None`。
- **預設參數只在定義時求值一次**：`def f(x, L=[])` 的 `L` 是同一個 list，會累積。預設用 `None` 再在函式內建立。
- 區域變數：函式內賦值就是區域變數，不影響外面；要改全域才用 `global`。
- `*args` 收位置引數成 tuple，`**kwargs` 收關鍵字引數成 dict。
- 排序鍵：`sorted(items, key=lambda kv: (-kv[1], kv[0]))`——先依值遞減、再依鍵遞增。
- 交換：`a, b = b, a`（tuple 解包）。
- 遞迴深度預設上限 1000（`sys.setrecursionlimit` 可調）。

## 七、單元 6–7：進位制、數學與二維 list

### 進位制與數學
| 運算 | 結果 |
| --- | --- |
| `bin(10)`、`hex(255)` | `'0b1010'`、`'0xff'` |
| `int("ff", 16)`、`int("101", 2)` | `255`、`5` |
| `format(255, "08b")` | `'11111111'`（補零到 8 位） |
| `math.gcd(12, 18)`、`math.lcm(12, 18)` | `6`、`36` |
| `pow(2, 10, 1000)` | `24`（模次方，競程常用） |
| `math.isqrt(17)` | `4`（整數平方根，不會有浮點誤差） |

- 取模：`(a * b) % m = ((a % m) * (b % m)) % m`；減法後要再 `% m` 避免負數（Python 本身的 `%` 結果非負，但別的語言不是）。

### 二維 list
- 建立：`grid = [[0] * C for _ in range(R)]`；讀取 `grid[r][c]`。
- 轉置：`list(zip(*m))`。
- 四個方向：`for dr, dc in ((1,0),(-1,0),(0,1),(0,-1))`，並檢查 `0 <= nr < R and 0 <= nc < C`。

## 八、易混淆重點與必背速查表

### 最容易混淆的幾組
| 容易搞錯 | 正確觀念 |
| --- | --- |
| `/` 與 `//` | `/` 浮點；`//` 向下取整（`-7//2 = -4`） |
| `-7 % 3` | `2`（與除數同號），不是 −1 |
| `b = a`（list） | 別名，不是複製；複製要 `a[:]` |
| `[[0]*2]*2` | 兩列是同一個 list |
| `a.sort()` | 回傳 None；不要寫 `a = a.sort()` |
| `"10" < "9"` | 字串比較是字典序 → 結果是 `True` |
| `def f(L=[])` | 預設值只建立一次，會累積 |
| `input()` | 回傳字串，要自己 `int()` |
| `for ... else` | else 只在沒有 break 時執行 |
| `range(a, b)` | 不含 b |
| `round(2.5)` | `2`，不是 3 |

### 必背速查
- 空容器、0、`None` 為假；`and`／`or` 回傳運算元。
- `divmod`、`gcd`、`pow(a, b, m)`、`bin`／`int(s, base)`、`sorted(key=)`。
- 單層迴圈 10⁶ 次沒問題；10⁷ 次要小心；10⁸ 次幾乎一定太慢。

### 單元 1–2 模擬測驗：輸入輸出、運算子、條件解答與解析

- **1. C**　`/` 是浮點除法，7/2 = 3.5；整數除法要用 `//`。
- **2. D**　`//` 向下取整（往負無限大），−3.5 → −4。C／C++ 的整數除法才是往 0 截斷得 −3。
- **3. D**　Python 的 `%` 結果與除數同號：−7 = (−3)×3 + 2，所以 −7 % 3 = 2。
- **4. B**　`divmod(a, b)` 回傳 (商, 餘數) 的 tuple。
- **5. C**　`round` 對恰好 .5 採『四捨六入五成雙』，2.5 取最近的偶數 2。
- **6. A**　0.1 與 0.2 無法精確表示成二進位浮點數，加起來是 0.30000000000000004。比較浮點數請用誤差範圍。
- **7. A**　字串乘整數是重複：`"5" * 3` = `"555"`。
- **8. B**　`sep` 控制多個引數之間的分隔字串，預設是空白。
- **9. C**　`split()` 得到 `['3','4']`，`map(int, …)` 轉成整數 3、4，相加 7。若忘了 `int`，`"3"+"4"` 會得到 `"34"`。
- **10. C**　`or` 回傳第一個為真的運算元（0 為假，所以回傳 `"a"`）。用 `repr` 印出可以看到引號。
- **11. B**　Python 允許連寫比較，`1 < 2 < 3` 等於 `1 < 2 and 2 < 3`。
- **12. B**　Python 的 int 是任意精度，只受記憶體限制；這在競程中少了很多溢位問題，但大數運算比較慢。

### 單元 3 模擬測驗：迴圈解答與解析

- **7. A**　`zip` 以最短的序列為準，多出來的 3 被丟棄。
- **8. B**　`enumerate(seq, 1)` 讓索引從 1 開始。
- **9. A**　`continue` 跳過本輪剩餘的部分，直接進入下一輪。
- **10. D**　先估算複雜度：O(n²) 在 n = 10⁵ 時是 10¹⁰；要改成 O(n log n) 或 O(n) 的做法（排序、雜湊、前綴和等）。
- **11. A**　`range(1, 4)` 是 1、2、3，每個加 1。
- **12. C**　迴圈不會自己停；沒有 break 或條件永遠為真就是無窮迴圈，在競程會 TLE。
