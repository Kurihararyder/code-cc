## 三、單元 1–2：設計流程、數字系統與布林代數

### 從 RTL 到晶片
| 階段 | 做什麼 | 工具（開源例） |
| --- | --- | --- |
| RTL 設計 | 用 Verilog 描述暫存器之間的資料流 | 編輯器 |
| 模擬 | 用 testbench 驗證行為 | iverilog＋vvp、Verilator、GTKWave |
| 邏輯合成 | RTL → 閘級網表（對應標準元件） | Yosys |
| 擺置繞線 | 決定元件位置與連線 | OpenROAD |
| 簽核 | 時序、DRC、LVS 等檢查 | OpenSTA、Magic |

- **可合成**的是「硬體」；`initial`、`#延遲`、`$display` 只用於模擬，合成器會忽略或報錯。
- 四值邏輯：`0`、`1`、`x`（未知）、`z`（高阻抗）。未初始化的 `reg` 在模擬中是 `x`。

### 數字系統
| 主題 | 重點 |
| --- | --- |
| 二補數 | N 位元範圍 −2^(N−1) … 2^(N−1)−1（8 位元：−128…127）；取負 = 全部反相再 +1 |
| 溢位 | 無號：結果超過 2^N−1 就回繞（`200+100` 在 8 位元得 44）；有號：兩正相加得負、兩負相加得正 |
| 十六進位 | 一位 = 4 位元：`0xA5` = `1010 0101` |
| 格雷碼 | 相鄰數只差一位；`g = b ^ (b >> 1)` |

### 布林代數與卡諾圖
- De Morgan：`~(A & B) = ~A | ~B`、`~(A | B) = ~A & ~B`。
- 最小項（minterm）之和 = SOP；最大項之積 = POS。`A'B + AB'` 就是 XOR。
- K-map：格子依**格雷碼**排列，相鄰格只差一個變數；圈 2^k 個相鄰的 1，可消去 k 個變數；圈越大、數量越少，式子越簡。
- don't care（X）可以當 0 或 1，用來把圈放大。

## 四、單元 3：Verilog 基礎語法

### 資料型態與向量
| 項目 | 說明 |
| --- | --- |
| `wire` | 連線。由 `assign` 或模組輸出驅動 |
| `reg` | 在 `always`／`initial` 內被賦值的變數；**不一定合成成暫存器** |
| `[7:0] x` | 8 位元向量，`x[7]` 是最高位 |
| `x[5:2]` | 取位元 5 到 2（4 位元） |
| `{a, b}` | 串接；`{3{2'b10}}` 重複 3 次 = `101010` |

### 運算子
| 類型 | 運算子 | 注意 |
| --- | --- | --- |
| 位元 | `& | ^ ~` | 逐位元，結果與運算元同寬 |
| 邏輯 | `&& || !` | 結果是 1 位元；非 0 當真 |
| 縮減 | `&x`、`|x`、`^x` | 把整個向量縮成 1 位元（`^` 是奇偶） |
| 相等 | `==`、`===` | `==` 遇到 x 結果為 x；`===` 逐位元比較含 x、z |
| 位移 | `<<`、`>>`、`>>>` | `>>>` 在有號數上是算術右移（保留符號位） |

### 位元寬度（最容易出錯）
- 字面值：`4'b1010`（寬度 ' 進位 數值）；`4'hFF` 超過寬度會被截斷成 `1111`；沒寫寬度的整數是 **32 位元**有號。
- 運算式的寬度取決於左右兩邊最寬者；賦值時**截斷高位**：`reg [3:0] s = 4'd15 + 4'd1` 得 0。
- `parameter` 可被實例化時覆寫，`localparam` 不行。模組連接建議用**具名連接** `.port(sig)`，不要用位置。

## 五、單元 4：組合電路

### 組合 always
```verilog
always @* begin
    y = 1'b0;            // 先給預設值
    if (sel) y = a;      // 然後覆寫
end
```
- 用 `always @*`（自動列出所有輸入）；組合邏輯用**阻塞賦值 `=`**。
- 敏感度列表漏寫（例如 `always @(a)` 卻用到 b）：模擬不會在 b 變化時更新，合成卻會當成完整組合邏輯 → **模擬與合成不一致**。
- **閂鎖（latch）**：組合 always 中，只要有某條路徑沒有給輸出賦值，就會推論出閂鎖。避免：先給預設值、`if` 寫滿 `else`、`case` 寫 `default`。
- `case` 比對值完全相同；`casez` 把 `z`／`?` 當 don't care，常用於優先權編碼；`casex` 連 x 也當 don't care（不建議）。
- 常見模組：多工器（mux）、解碼器、編碼器、優先權編碼器、全加器（`sum = a^b^cin`，`cout = ab + cin(a^b)`）、比較器、ALU。

## 六、單元 5：序列電路

### 時脈 always
```verilog
always @(posedge clk) begin      // 同步重置
    if (rst) q <= 0;
    else     q <= d;
end
always @(posedge clk or posedge rst)   // 非同步重置
```
- **序列邏輯用非阻塞賦值 `<=`**：同一個時脈邊緣上，右邊都用「更新前」的值，所有暫存器同時更新。
- `a <= b; b <= a;` 交換兩個暫存器；若寫成 `a = b; b = a;` 兩個都會變成舊的 b。
- 同步重置需要時脈邊緣才生效；非同步重置不需時脈，放進敏感度列表。
- 常見電路：D 正反器、帶致能的暫存器、計數器（溢位回繞）、移位暫存器（`q <= {q[2:0], din}`）、時脈除頻、邊緣偵測（`rise = x & ~x_d`）。
- 規則：**組合用 `=`，序列用 `<=`，同一個變數不要兩種混用**。

## 七、單元 6：有限狀態機

| 比較 | Moore | Mealy |
| --- | --- | --- |
| 輸出取決於 | 只有目前狀態 | 目前狀態與輸入 |
| 輸出變化時機 | 下一個時脈邊緣之後 | 輸入改變時立即（組合） |
| 狀態數 | 通常較多 | 通常較少 |

- 推薦寫法：**兩段式**——一個 `always @(posedge clk)` 存狀態，一個 `always @*` 算下一狀態與輸出。
- 編碼：二進位（N 個狀態需 ⌈log₂N⌉ 個 FF）、one-hot（N 個 FF，解碼簡單，FPGA 常用）、格雷碼。
- 一定要有 `default` 與重置狀態，處理非法狀態。
- 序列偵測器：重疊偵測時，比對成功後要回到「保留可重疊前綴」的狀態，而不是回到起點。

## 八、單元 7：Testbench 與波形

- `initial` 只執行一次；`always #5 clk = ~clk;` 產生週期 10 個時間單位的時脈。
- `` `timescale 1ns/1ps `` 讓 `#5` 代表 5 ns。
- 系統工作：`$display`（立即印）、`$monitor`（訊號變就印）、`$finish`（結束模擬）、`$dumpfile`／`$dumpvars`（寫波形）、`$random`／`$urandom`。
- **在時脈負緣（或上升緣之後）驅動輸入**，避免與設計在同一邊緣競爭（race）。
- **自我檢查**：用 `!==` 比對預期值，不符就印 `ERROR`，最後印 `PASS`／`FAIL`；不要靠肉眼看波形。
- 除錯順序：看編譯錯誤 → 看 x（沒初始化／沒重置）→ 看波形找第一個不對的時間點 → 往驅動它的訊號追。

## 九、易混淆重點與必背速查表

### 最容易混淆的幾組
| 容易搞錯 | 正確觀念 |
| --- | --- |
| `reg` = 暫存器？ | 不一定。組合 always 裡的 `reg` 是組合邏輯；只有時脈 always 裡賦值的才變成 FF |
| `=` 與 `<=` | 組合用 `=`；序列用 `<=`；交換暫存器必須用 `<=` |
| `&` 與 `&&` | `&` 逐位元、結果同寬；`&&` 邏輯、結果 1 位元 |
| `==` 與 `===` | 含 x 時 `==` 得 x；`===` 得 0 或 1 |
| `>>` 與 `>>>` | 後者在有號數上保留符號位 |
| 沒寫 else／default | 產生閂鎖 |
| `always @(a)` 漏寫 b | 模擬與合成不一致；一律用 `@*` |
| Moore 與 Mealy | Moore 輸出只看狀態（晚一拍）；Mealy 看輸入（當拍） |
| 同步與非同步重置 | 非同步重置寫進敏感度列表，不需時脈 |
| 4'hFF | 被截斷成 `1111`，不是 255 |

### 必背速查
- 8 位元有號：−128…127；`200+100` 無號回繞 = 44；`-x = ~x + 1`。
- 格雷碼：`b ^ (b >> 1)`；one-hot：N 狀態 N 個 FF；二進位：⌈log₂N⌉ 個 FF。
- `{N{x}}` 重複；`x[a:b]` 取位元；`^x` 奇偶；`&x`、`|x` 縮減。
- 寫組合 always：`@*`、`=`、預設值、`default`。

### 單元 1–2 模擬測驗：流程、數字系統、布林代數解答與解析

- **1. A**　先有 RTL 並用模擬確認行為，再合成成閘級網表，接著擺置繞線，最後做時序與規則簽核。
- **2. D**　延遲與系統工作是模擬構造，合成器不會（也不能）把它們變成硬體；其餘三項都是可合成的描述。
- **3. C**　未初始化的 reg 在四值模擬中是未知值 `x`；`z` 是高阻抗，用於未驅動的 wire。
- **4. C**　最高位是符號位，`10000000` 是 8 位元二補數能表示的最小值 −128。注意它的絕對值 128 無法用 8 位元有號數表示。
- **5. C**　N 位元二補數範圍是 −2^(N−1) 到 2^(N−1)−1，8 位元即 −128 到 127。負數比正數多一個。
- **6. D**　300 超過 8 位元無號範圍 255，高位被截掉：300 − 256 = 44。
- **7. D**　反相一個 AND，等於各輸入反相後做 OR（反之亦然），這是把 NAND 與 OR 互換的基礎。
- **8. B**　0110 ^ 0011 = 0101。格雷碼的特性是相鄰兩個數只差一個位元。
- **9. C**　圈 2^k 個相鄰的 1 可消去 k 個變數；4 = 2²，所以消去 2 個，乘積項剩 2 個變數。
- **10. C**　十六進位每一位對應 4 位元：A = 1010、5 = 0101。
- **11. C**　A 與 B 不同時輸出 1，就是 XOR。XNOR 則是相同時輸出 1。
- **12. C**　~0101 = 1010，加 1 得 1011；它在 4 位元二補數中代表 −5。

### 單元 4 模擬測驗：組合電路與閂鎖解答與解析

- **3. D**　改成時脈 always 只是把閂鎖變成正反器——電路行為不同，而不是修正遺漏的分支。真正的修正是讓每條路徑都賦值。
- **4. A**　`casez` 把 `?`（即 z）當 don't care，所以 `1???` 只要最高位是 1 就符合；第一個符合的分支執行。
- **5. D**　1+1+1 = 3 = 二進位 11：sum = a^b^cin = 1，cout = 1。
- **6. B**　敏感度列表只有 a，b 改變時區塊不執行，y 保持舊值 0；但合成出的電路會是完整的 `a & b`，造成模擬與硬體不一致。
- **7. B**　多工器是組合邏輯，`case` 清楚對應選擇線；加上 `default` 可避免閂鎖。
- **8. D**　if/else if 的先後順序就是優先順序；`casez` 的 `?` 讓你只寫關心的位元。
- **9. C**　規則是組合用 `=`、序列用 `<=`、不混用。混用會讓賦值時機與讀取順序交織，易產生 race。
- **10. B**　`casex` 會把 x 也當 don't care，輸入出現 x 時反而悄悄通過，不推薦；`default` 對合成同樣重要，用來避免閂鎖。

### 單元 5 模擬測驗：序列電路解答與解析

- **1. C**　非阻塞賦值讓同一邊緣上所有暫存器都用更新前的值，行為與真實 FF 一致；用 `=` 會因賦值順序產生競爭。

- **4. A**　非同步重置不需要時脈就能立刻清除暫存器，所以 rst 的邊緣要能觸發區塊；同步重置則等下一個時脈邊緣才生效。
- **5. B**　4 位元無法表示 16，高位被丟棄，計數器回繞到 0。
- **6. B**　每拍左移一位、最低位補入 din：0000 → 0001 → 0011 → 0111。
- **7. B**　FF 在邊緣當下鎖存輸入；若輸入在建立／保持時間窗內變化，會違反時序，行為不確定。模擬中非阻塞賦值也有同樣效果。
- **8. C**　這是同步與非同步重置的取捨：非同步不依賴時脈，但釋放重置時要小心時序（重置移除同步）。
- **9. C**　上升緣 = 現在 1 且上一拍 0；下降緣則是 `~x & x_d`；任何變化是 `x ^ x_d`。
- **10. A**　`#` 延遲不可合成；正確做法是用計數器數時脈邊緣，並且在時脈 always 內更新輸出暫存器。

### 單元 7–8 模擬測驗：Testbench、波形與綜合解答與解析

- **1. A**　每 5 個單位翻轉一次，所以高 5、低 5，週期 10。
- **2. B**　第一個數字是時間單位（1ns），`#5` 就是 5 × 1ns；第二個數字是模擬精度。
- **3. A**　`$monitor` 設定一次後在背景持續監看，同一時間只能有一個有效。
- **4. D**　同一個模擬時刻，各個區塊的執行順序不保證；在遠離取樣邊緣的時間點驅動輸入就不會有誤解。
- **5. D**　`!=` 遇到 x 結果是 x，`if (x)` 視為假，錯誤會悄悄通過；`!==` 的結果只會是 0 或 1。
- **6. A**　沒有 `$finish`（或時脈一直在跑）的 testbench 不會自行結束，要用它收尾；波形檔由 `$dumpfile`／`$dumpvars` 產生。
- **7. B**　要重複的行為（如時脈）用 `always`，或在 `initial` 裡寫 `forever`。
- **8. A**　x 通常表示沒有被驅動或沒有初值；追到第一個出現 x 的時間點與訊號，往它的驅動來源回推。
- **9. B**　驗證要能由別人一鍵重跑、並自動判斷成敗；截圖和口頭說明都不能自動檢查。
- **10. B**　`assign cnt = cnt + 1` 是組合迴路；缺 else 的組合 always 會產生閂鎖；`initial` 不可合成。
