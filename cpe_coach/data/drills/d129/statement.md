# d129 切繩子

**階段 2　難度 ★★★　主題：二分搜尋／答案二分**

有 n 條繩子，長度分別是 a₁…aₙ（整數）。要切出 k 段『長度相同的整數長度』繩子（每條繩子可以切成好幾段，剩下的零頭不用），這個共同長度最大是多少？如果連長度 1 都切不出 k 段，輸出 0。

## 輸入
第一行 n k（1 ≤ n ≤ 10^5，1 ≤ k ≤ 10^9），第二行 n 個整數（1 ≤ aᵢ ≤ 10^9）。

## 輸出
一個整數。

## 範例
輸入：
```
4 11
802 743 457 539
```
輸出：
```
200
```

## 這題在練什麼
答案長度 L 越大，能切出的段數越少（單調），所以可以對 L 做二分搜尋；檢查函式是 `sum(a // L) >= k`。
