# d111 BMI

**階段 1　難度 ★★　主題：浮點數輸出／分級**

每行兩個整數 w h（體重 w 公斤、身高 h 公分），BMI = w ÷ (h/100)²。輸出 `BMI 類別`：BMI 四捨五入到小數點後 1 位；類別看『四捨五入前』的 BMI：小於 18.5 是 `UNDER`，18.5 以上小於 24 是 `NORMAL`，24 以上小於 27 是 `OVER`，27 以上是 `OBESE`。測資保證 BMI 不會剛好落在『第二位小數是 5 的進位邊界』。

## 輸入
每行 `w h`（30 ≤ w ≤ 200，100 ≤ h ≤ 220），讀到 EOF。

## 輸出
每行 `BMI 類別`，例如 `22.9 NORMAL`。

## 範例
輸入：
```
70 175
```
輸出：
```
22.9 NORMAL
```

## 這題在練什麼
類別的邊界看原始值、顯示看四捨五入後的值——兩者不一定一致（例如 BMI 23.96 顯示成 24.0，類別卻是 NORMAL）。
