# d124 後序運算式求值

**階段 1　難度 ★★　主題：stack／運算式**

每行是一個後序（postfix）運算式：整數與 `+` `-` `*` 以空格隔開。依序處理每個符號，遇到數字就放進堆疊，遇到運算子就取出最上面兩個數 a（先放入的）與 b（後放入的），計算 a 運算子 b 再放回去。最後輸出堆疊裡唯一剩下的數。保證運算式合法。

## 輸入
每行最多 1000 個符號，整數 0–10^9，讀到 EOF。

## 輸出
每行一個整數（可能是負數或很大的整數）。

## 範例
輸入：
```
3 4 + 2 *
```
輸出：
```
14
```

## 這題在練什麼
『先放入的是左運算元』這個順序對減法很重要。
