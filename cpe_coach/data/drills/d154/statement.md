# d154 最短路徑有幾條

**階段 3　難度 ★★★　主題：最短路徑／計數**

無向加權圖 n 個點 m 條邊（邊權 ≥ 1）。從點 1 到點 n 的最短路徑長度是多少、總共有幾條不同的最短路徑？路徑數對 1000000007 取餘數。到不了點 n 時輸出 `-1 0`。

## 輸入
第一行 n m（1 ≤ n ≤ 10^4，0 ≤ m ≤ 5×10^4），接著 m 行 `u v w`（1 ≤ w ≤ 1000，可能有重邊；重邊算不同的邊）。

## 輸出
一行：最短距離 路徑數。

## 範例
輸入：
```
4 5
1 2 1
1 3 1
2 4 1
3 4 1
2 3 1
```
輸出：
```
2 2
```

## 這題在練什麼
Dijkstra 的過程中同時記 cnt[v]：找到更短的距離就把 cnt 設為來源的 cnt，距離相等就把來源的 cnt 加進去。
