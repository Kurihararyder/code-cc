# d021 Primality Test

**Stage 0 · Difficulty ★ · Topic: Math, loops**

Decide whether the integer n is a prime (1 is not a prime). Print `YES` or `NO`.

## Input
One integer n per line (1 ≤ n ≤ 10^9), at most 100 lines, until EOF.

## Output
For each line print YES or NO.

## Sample Input
```
7
```

## Sample Output
```
YES
```

## Notes
Trial division; for n up to 10^9 you only need to try divisors up to 31623.
