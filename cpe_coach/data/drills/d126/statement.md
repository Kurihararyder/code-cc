# d126 多條件排名

**階段 2　難度 ★★　主題：自訂排序／混合方向**

n 位選手，每行 `姓名 年齡 分數`。排序規則：分數高的在前；分數相同時，年齡小的在前；年齡也相同時，姓名字典序（ASCII）小的在前。依序輸出 `姓名 年齡 分數`。

## 輸入
第一行 n（1 ≤ n ≤ 10^5），之後 n 行：姓名是不含空白的英文字母（長度 ≤ 10），年齡 1–120，分數 0–1000。

## 輸出
n 行。

## 範例
輸入：
```
4
amy 20 90
bob 19 90
cat 20 95
dan 19 90
```
輸出：
```
cat 20 95
bob 19 90
dan 19 90
amy 20 90
```

## 這題在練什麼
key 可以用 tuple：要『降序』的欄位取負號，其他欄位維持升序。
