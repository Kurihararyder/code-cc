# d042 Spiral Matrix

**Stage 1 · Difficulty ★ · Topic: 2D simulation**

Given n, print the n×n spiral matrix: start with 1 in the top-left corner and fill 1..n² clockwise towards the centre. Separate the numbers in a row by spaces.

## Input
n ≤ 30.

## Output
n lines.

## Sample Input
```
3
```

## Sample Output
```
1 2 3
8 9 4
7 6 5
```

## Notes
The standard way to write 'turning' simulations.
