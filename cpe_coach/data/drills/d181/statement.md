# d181 三角形的面積與種類

**階段 4　難度 ★★　主題：計算幾何／三角形**

每行六個整數 `x1 y1 x2 y2 x3 y3`，是平面上三個點。輸出 `面積的兩倍 種類`：三點共線（含重合）時種類是 `DEGENERATE`（面積 0）；否則依最大的內角分成 `ACUTE`（三個內角都小於 90 度）、`RIGHT`（有一個直角）、`OBTUSE`（有一個鈍角）。

## 輸入
每行座標絕對值 ≤ 10^6，讀到 EOF，最多 1000 行。

## 輸出
每行 `整數 單字`。

## 範例
輸入：
```
0 0 4 0 0 3
```
輸出：
```
12 RIGHT
```

## 這題在練什麼
全部用整數：面積的兩倍是叉積的絕對值；角度用內積的正負判斷（內積 > 0 銳角、= 0 直角、< 0 鈍角），完全不需要三角函數。
