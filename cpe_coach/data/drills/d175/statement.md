# d175 指派工作

**階段 3　難度 ★★★　主題：位元遮罩 DP／指派**

n 個人要做 n 件工作，每人恰好做一件、每件工作恰好一個人做。第 i 個人做第 j 件工作的成本是 c[i][j]。求最小的總成本。

## 輸入
第一行 n（1 ≤ n ≤ 12），接著 n 行各 n 個整數（0 ≤ c ≤ 1000）。

## 輸出
一個整數。

## 範例
輸入：
```
3
9 2 7
6 4 3
5 8 1
```
輸出：
```
9
```

## 這題在練什麼
dp[mask] = 前 popcount(mask) 個人已經做完 mask 這些工作的最小成本；下一個人試每一件還沒被選的工作。
