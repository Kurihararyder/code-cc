# d169 數字三角形

**階段 3　難度 ★★　主題：網格 DP／三角形**

數字排成三角形：第 i 列有 i 個數。從最上面的數出發，每一步走到下一列『正下方』或『右下方』的相鄰數，一路走到最底列，求經過的數字總和最大是多少。

## 輸入
第一行 n（1 ≤ n ≤ 1000，列數）；接著第 i 行有 i 個整數（絕對值 ≤ 10^4）。

## 輸出
一個整數。

## 範例
輸入：
```
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```
輸出：
```
30
```

## 這題在練什麼
由下往上做：每個位置的最佳值 = 自己 + 下方兩個位置較大者。
