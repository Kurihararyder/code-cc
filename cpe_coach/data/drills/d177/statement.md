# d177 快速冪取模

**階段 3　難度 ★★　主題：數論／快速冪**

對每組 a b m，輸出 aᵇ mod m。b 可以非常大（到 10^18），不能一個一個乘。m = 1 時答案是 0。

## 輸入
每行三個整數 a b m（0 ≤ a ≤ 10^9，0 ≤ b ≤ 10^18，1 ≤ m ≤ 10^9），最多 1000 行，讀到 EOF。a = 0 且 b = 0 時，約定 0⁰ = 1（再對 m 取餘數）。

## 輸出
每行一個整數。

## 範例
輸入：
```
2 10 1000
```
輸出：
```
24
```

## 這題在練什麼
把 b 用二進位拆開：每次平方 a、遇到 1 的位元就乘進答案，每一步都對 m 取餘數。請自己寫迴圈（不要直接用內建的三參數 pow）練習。
