# d119 骰子滾動

**階段 1　難度 ★★　主題：網格模擬／狀態**

一顆骰子（相對的兩面和為 7）的初始狀態：上面 1、北面 2、東面 3、西面 4、南面 5、下面 6。每行一串指令，由 `N` `S` `E` `W` 組成，表示依序把骰子向北、南、東、西『翻滾』一格（向北翻滾時，原本的上面轉到北面，原本的南面轉到上面；其他方向以此類推）。輸出每行指令做完之後的上面點數。空行代表一次也不滾動，答案是 1。

## 輸入
每行一串指令（長度 ≤ 10^5，可能是空行），讀到 EOF。

## 輸出
每行一個整數。

## 範例
輸入：
```
N
```
輸出：
```
5
```

## 這題在練什麼
只要追蹤『上、北、東』三個面（其餘由 7 減），每次翻滾就是換值。
