# d166 最長遞增子序列的個數

**階段 3　難度 ★★★　主題：序列 DP／計數**

給長度 n 的整數序列。『最長嚴格遞增子序列』可能有很多條（用位置不同就算不同的子序列）。輸出最長長度，以及長度達到最長的子序列有幾條，個數對 1000000007 取餘數。

## 輸入
第一行 n（1 ≤ n ≤ 2000），第二行 n 個整數（絕對值 ≤ 10^9）。

## 輸出
一行：長度 個數。

## 範例
輸入：
```
5
1 3 5 4 7
```
輸出：
```
4 2
```

## 這題在練什麼
每個位置 i 記錄 (以 i 結尾的最長長度 L[i], 這種長度的方法數 C[i])，轉移時長度更長就取代、長度相同就累加。
