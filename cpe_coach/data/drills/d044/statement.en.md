# d044 Left-to-Right Expression

**Stage 1 · Difficulty ★ · Topic: Parsing**

Each line is an expression with spaces between tokens: integers alternating with + - *, for example `3 + 4 * 2`. **Ignore operator precedence and always evaluate from left to right** (so 3+4*2 = 14). Print the result.

## Input
Integers are 0–1000, at most 20 numbers per line. Read until EOF.

## Output
One integer per line.

## Sample Input
```
3 + 4 * 2
```

## Sample Output
```
14
```

## Notes
Later, d095 challenges you with precedence and parentheses.
