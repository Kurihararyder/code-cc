# d147 騎士的最少步數

**階段 3　難度 ★★　主題：BFS／最短步數**

N×N 的棋盤（行列都從 1 算起），西洋棋騎士每步走『日』字（水平 2 格垂直 1 格，或水平 1 格垂直 2 格）。有 t 個詢問，每個給棋盤大小與起點、終點，輸出最少步數；走不到輸出 -1。

## 輸入
第一行 t（1 ≤ t ≤ 100）；之後 t 行，每行 `N r1 c1 r2 c2`（1 ≤ N ≤ 50，座標都在棋盤內）。

## 輸出
每個詢問一行。

## 範例
輸入：
```
3
8 1 1 8 8
3 1 1 3 3
3 2 2 1 1
```
輸出：
```
6
4
-1
```

## 這題在練什麼
BFS 求最少步數；N 很小的棋盤（如 2×2、3×3）會有走不到的格子。
