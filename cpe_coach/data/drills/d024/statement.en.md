# d024 Star Pyramid

**Stage 0 · Difficulty ★ · Topic: Loops, formatting**

Given n, print a centered pyramid with n rows: row i (starting from 1) begins with n-i spaces followed by 2i-1 `*` characters. There must be no trailing spaces at the end of a line.

## Input
One integer n per line (1 ≤ n ≤ 50).

## Output
n lines.

## Sample Input
```
3
```

## Sample Output
```
  *
 ***
*****
```

## Notes
A string can be repeated with *; spaces in the output count as content.
