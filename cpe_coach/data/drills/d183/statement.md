# d183 兩個矩形的交集面積

**階段 4　難度 ★★　主題：計算幾何／矩形**

每行八個整數 `x1 y1 x2 y2 x3 y3 x4 y4`：第一個矩形的左下角 (x1,y1) 與右上角 (x2,y2)，第二個矩形的左下角 (x3,y3) 與右上角 (x4,y4)（邊都與座標軸平行，保證 x1<x2、y1<y2、x3<x4、y3<y4）。輸出兩個矩形重疊部分的面積；只有邊或角碰在一起時面積是 0。

## 輸入
座標絕對值 ≤ 10^9，讀到 EOF，最多 1000 行。

## 輸出
每行一個整數（可能超過 64 位元範圍的一半，Python 不用擔心）。

## 範例
輸入：
```
0 0 4 4 2 2 6 6
```
輸出：
```
4
```

## 這題在練什麼
水平方向的重疊長度 = max(0, min(x2,x4) − max(x1,x3))；垂直方向同理；兩者相乘。
