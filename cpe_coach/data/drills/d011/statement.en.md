# d011 Multiplication Table

**Stage 0 · Difficulty ★ · Topic: Loops, formatting**

Given n (1–9), print the multiplication table of n: exactly 9 lines, where line i has the form `n*i=result`.

## Input
One integer n.

## Output
9 lines.

## Sample Input
```
3
```

## Sample Output
```
3*1=3
3*2=6
3*3=9
3*4=12
3*5=15
3*6=18
3*7=21
3*8=24
3*9=27
```

## Notes
The output must match the sample exactly (no extra spaces).
