# d098 三角形種類

**階段 0　難度 ★　主題：條件判斷**

每行三個正整數 a b c 代表三條邊長。若這三條邊不能圍成三角形（兩短邊之和 ≤ 最長邊，退化成線段也算不能），輸出 `NOT`；否則依序判斷：三邊都相等輸出 `EQUILATERAL`，恰有兩邊相等輸出 `ISOSCELES`，否則輸出 `SCALENE`。

## 輸入
每行三個整數（1–10^9），讀到 EOF。

## 輸出
每行一個單字。

## 範例
輸入：
```
3 4 5
```
輸出：
```
SCALENE
```

## 這題在練什麼
先判斷能不能成立，再判斷種類；『兩短邊之和等於長邊』是最常漏掉的邊界。
