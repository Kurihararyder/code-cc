# d059 The Lonely Number

**Stage 2 · Difficulty ★ · Topic: Bit operations**

Given n integers (n is odd), exactly one of them appears once and all the others appear exactly twice. Find the lonely one.

## Input
The first line contains n (≤ 30001); the second line contains n integers (absolute value ≤ 10^9).

## Output
One integer.

## Sample Input
```
5
1 2 3 2 1
```

## Sample Output
```
3
```

## Notes
XOR also works for negative numbers in Python.
