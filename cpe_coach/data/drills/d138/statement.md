# d138 區間覆蓋

**階段 2　難度 ★★★　主題：貪心／區間覆蓋**

數線上有 n 個閉區間 [lᵢ, rᵢ]。要選出最少的區間，讓線段 [0, L] 上的每一點都至少被一個選到的區間蓋住（區間端點相接視為蓋住）。輸出最少需要幾個，做不到就輸出 -1。

## 輸入
第一行 L n（1 ≤ L ≤ 10^9，1 ≤ n ≤ 10^5）；接著 n 行 `l r`（0 ≤ l < r ≤ 10^9）。

## 輸出
一個整數。

## 範例
輸入：
```
10 3
0 5
4 10
3 7
```
輸出：
```
2
```

## 這題在練什麼
貪心：目前已蓋到 cur，在所有 l ≤ cur 的區間中挑 r 最大的；這需要先把區間依 l 排序。
