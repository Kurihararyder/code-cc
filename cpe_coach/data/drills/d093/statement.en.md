# d093 Euler's Totient

**Stage 4 · Difficulty ★★★ · Topic: Number theory**

φ(n) is the number of integers in 1..n that are coprime to n. For each query n print φ(n).

## Input
The first line contains q (≤ 20000); then q lines with n ≤ 10^6.

## Output
One line per query.

## Sample Input
```
5
1
2
6
10
12
```

## Sample Output
```
1
1
2
4
4
```
