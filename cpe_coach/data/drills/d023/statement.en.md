# d023 Fibonacci

**Stage 0 · Difficulty ★ · Topic: Loops, functions**

F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2). Given n (0 ≤ n ≤ 90), print F(n).

## Input
One integer per line, until EOF.

## Output
One answer per line.

## Sample Input
```
10
```

## Sample Output
```
55
```

## Notes
A recursive version takes forever for n=90 — the first lesson in complexity.
