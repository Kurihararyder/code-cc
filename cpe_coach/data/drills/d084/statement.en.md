# d084 Longest Palindromic Substring

**Stage 4 · Difficulty ★★★ · Topic: Strings, performance**

Print the length of the longest palindromic substring of the string.

## Input
One lowercase string per line (length ≤ 5000), until EOF, at most 5 lines.

## Output
One integer per line.

## Sample Input
```
babad
```

## Sample Output
```
3
```

## Notes
A string of identical characters is the worst input for expand-around-centre.
