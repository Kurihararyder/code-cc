# d035 Division and Decimal Places

**Stage 1 · Difficulty ★ · Topic: Floating-point format**

Each line contains two positive integers a and b. Print a/b **rounded to 4 digits after the decimal point**.

## Input
a, b ≤ 10^6, until EOF. The data guarantees that no value falls exactly on a rounding boundary.

## Output
One answer per line.

## Sample Input
```
1 3
```

## Sample Output
```
0.3333
```

## Notes
Floating-point formatting. If a problem demands an exact decimal expansion, integer arithmetic or the decimal module is safer.
