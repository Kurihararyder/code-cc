# d151 最大的朋友圈

**階段 3　難度 ★★　主題：並查集／維護群組大小**

一開始有 n 個人，每個人自己一個群組。依序發生 m 次『a 和 b 變成朋友』（他們所在的兩個群組合併成一個；已經在同一群組就什麼都不變）。每次操作之後，輸出目前最大的群組有幾個人。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，1 ≤ m ≤ 10^5）；接著 m 行 `a b`（1 ≤ a, b ≤ n，可能 a = b）。

## 輸出
m 行，每次操作後各一個整數。

## 範例
輸入：
```
5 4
1 2
3 4
2 3
5 5
```
輸出：
```
2
2
4
4
```

## 這題在練什麼
並查集同時維護每個根的群組大小與全域最大值；合併時只可能讓最大值變大，不需要重算。
