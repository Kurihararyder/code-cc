# d187 最近共同祖先

**階段 4　難度 ★★★★　主題：樹／最近共同祖先**

一棵以 1 號點為根的樹（n 個點、n−1 條邊，邊是無向給出的）。有 q 個詢問 `a b`，輸出 a 和 b 的最近共同祖先（同時是兩者祖先、且深度最大的點；一個點算自己的祖先）。

## 輸入
第一行 n q（1 ≤ n, q ≤ 5×10^4）；接著 n−1 行 `u v`；再接著 q 行 `a b`。

## 輸出
每個詢問一行。

## 範例
輸入：
```
7 3
1 2
1 3
2 4
2 5
3 6
3 7
4 5
4 6
7 7
```
輸出：
```
2
1
7
```

## 這題在練什麼
倍增法：up[k][v] 是 v 往上 2^k 層的祖先。先把兩點拉到同一深度，再一起往上跳。用 BFS 建立深度與父節點，避免遞迴。
