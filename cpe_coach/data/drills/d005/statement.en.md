# d005 Odd or Even

**Stage 0 · Difficulty ★ · Topic: Conditions**

Decide whether the integer n is odd or even. Print `odd` or `even`.

## Input
One integer n per line (|n| ≤ 10^9; it may be negative or zero), until EOF.

## Output
For each line print odd or even.

## Sample Input
```
4
```

## Sample Output
```
even
```
