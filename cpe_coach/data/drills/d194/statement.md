# d194 樹上最大點權路徑

**階段 4　難度 ★★★★　主題：樹 DP／最大路徑和**

一棵 n 個點的樹，每個點有權重（可能是負數）。找一條路徑（至少包含一個點，兩端可以是任何點，路徑上的點不重複），使路徑上點的權重總和最大，輸出這個最大總和。

## 輸入
第一行 n（1 ≤ n ≤ 10^5）；第二行 n 個整數（絕對值 ≤ 10^9）；接著 n−1 行 `u v`。

## 輸出
一個整數。

## 範例
輸入：
```
5
1 2 3 4 5
1 2
2 3
2 4
4 5
```
輸出：
```
14
```

## 這題在練什麼
樹 DP：down[u] = w[u] + max(0, 最大的 down[child])；經過 u 的最佳路徑 = w[u] + 最大兩個 max(0, down[child]) 的和。用迭代順序處理（避免遞迴過深）。
