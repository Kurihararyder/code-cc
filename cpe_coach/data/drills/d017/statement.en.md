# d017 Sequence Statistics

**Stage 0 · Difficulty ★ · Topic: Lists**

The first line contains n; the second line contains n integers. Print the minimum, the maximum and the average (with 2 digits after the decimal point), separated by spaces.

## Input
n ≤ 1000.

## Output
One line: min max avg.

## Sample Input
```
5
1 2 3 4 5
```

## Sample Output
```
1 5 3.00
```

## Notes
Basic list operations; formatting the average.
