# d105 成績總表

**階段 0　難度 ★★　主題：dict／彙總**

第一行 n，接著 n 行 `姓名 科目 分數`（姓名、科目是不含空白的英文字母，分數是 0–100 的整數）。同一位學生可能出現很多次（不同科目）。依姓名的字典序（ASCII 順序，大寫在小寫之前）輸出每位學生的 `姓名 總分 科目數`。

## 輸入
第一行 n（1 ≤ n ≤ 10^5），之後 n 行。同一位學生的同一科目不會重複出現。

## 輸出
每位學生一行。

## 範例
輸入：
```
5
amy math 90
bob math 80
amy art 70
cat math 100
bob art 60
```
輸出：
```
amy 160 2
bob 140 2
cat 100 1
```

## 這題在練什麼
dict 以姓名為 key 累加；輸出前 sorted(d)。
