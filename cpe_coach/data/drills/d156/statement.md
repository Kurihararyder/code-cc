# d156 最小瓶頸路徑

**階段 3　難度 ★★★　主題：最小生成樹／瓶頸路**

無向加權圖 n 個點 m 條邊。一條路徑的『瓶頸』是路徑上最重的那條邊的權重。對每個詢問 `a b`，找一條從 a 到 b 的路徑使瓶頸最小，輸出這個最小瓶頸；a = b 時輸出 0，a 與 b 不連通時輸出 -1。

## 輸入
第一行 n m q（1 ≤ n ≤ 1000，0 ≤ m ≤ 5000，1 ≤ q ≤ 1000），接著 m 行 `u v w`（1 ≤ w ≤ 10^6，可能有重邊與自環），再接著 q 行 `a b`。

## 輸出
每個詢問一行。

## 範例
輸入：
```
4 4 3
1 2 5
2 3 3
1 3 9
3 4 1
1 4
1 3
2 2
```
輸出：
```
5
5
0
```

## 這題在練什麼
最小瓶頸路徑一定出現在最小生成樹上：先做 Kruskal，之後每個詢問在樹上找 a 到 b 的路徑最大邊。
