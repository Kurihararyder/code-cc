# d174 切木棒

**階段 3　難度 ★★★　主題：區間 DP／切割**

一根長度 L 的木棒，要在 k 個指定的位置各切一刀（位置是離左端的距離，彼此不同，都在 0 和 L 之間）。每切一刀的成本是『被切的那一段目前的長度』，切的順序可以自己決定。求最小的總成本。有 t 組測資。

## 輸入
第一行 t（1 ≤ t ≤ 20）；每組兩行：`L k`（1 ≤ k ≤ 100，k < L ≤ 10^6），以及 k 個遞增的位置。

## 輸出
每組一行。

## 範例
輸入：
```
2
10 3
2 4 7
100 3
25 50 75
```
輸出：
```
20
200
```

## 這題在練什麼
把兩端 0 和 L 也當成切點，dp[i][j] = 切掉 i 到 j 之間所有切點的最小成本 = min over m of (dp[i][m] + dp[m][j]) + (位置[j] − 位置[i])。
