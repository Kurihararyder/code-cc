# d172 石子合併

**階段 3　難度 ★★★　主題：區間 DP／合併**

n 堆石子排成一列，第 i 堆有 aᵢ 顆。每次只能把『相鄰的兩堆』合併成一堆，成本是這兩堆的石子數總和。把全部合併成一堆，最少的總成本是多少？

## 輸入
第一行 n（1 ≤ n ≤ 100），第二行 n 個整數（1 ≤ aᵢ ≤ 1000）。

## 輸出
一個整數（n = 1 時是 0）。

## 範例
輸入：
```
4
4 1 1 4
```
輸出：
```
18
```

## 這題在練什麼
dp[i][j] = 合併第 i 到 j 堆的最少成本 = min over k of (dp[i][k] + dp[k+1][j]) + sum(i..j)；注意和『合併成本（d052）』不同，這裡只能合併相鄰的堆。
