# d025 Number of Divisors

**Stage 0 · Difficulty ★ · Topic: Math, functions**

For each positive integer n, print how many positive divisors it has.

## Input
One integer n per line (≤ 10^6), at most 1000 lines, until EOF.

## Output
One answer per line.

## Sample Input
```
12
```

## Sample Output
```
6
```

## Notes
The trick of finding divisors in pairs; you will use it in all number theory later.
