# d130 區間加值

**階段 2　難度 ★★★　主題：差分陣列**

一個長度 n 的陣列一開始全是 0。接著有 m 個操作 `l r v`：把第 l 到第 r 個位置（含，1 起算）都加上 v。做完所有操作後，輸出整個陣列。

## 輸入
第一行 n m（1 ≤ n, m ≤ 2×10^5）；接著 m 行 `l r v`（1 ≤ l ≤ r ≤ n，|v| ≤ 10^4）。

## 輸出
一行 n 個整數，以空格隔開。

## 範例
輸入：
```
5 3
1 3 2
2 5 -1
3 3 10
```
輸出：
```
2 1 11 -1 -1
```

## 這題在練什麼
不要每次操作都跑迴圈（O(nm)）：在差分陣列 `d[l] += v; d[r+1] -= v`，最後做一次前綴和。
