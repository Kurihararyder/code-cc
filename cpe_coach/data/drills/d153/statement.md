# d153 拓撲順序唯一嗎

**階段 3　難度 ★★　主題：拓撲排序／唯一性**

有向圖 n 個點 m 條邊 `u v`（u 必須排在 v 前面，可能有重複的邊）。如果圖有環輸出 `CYCLE`（自環也算）；否則如果合法的排列順序恰好只有一種輸出 `UNIQUE`，有兩種以上輸出 `MULTIPLE`。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），接著 m 行 `u v`。

## 輸出
`CYCLE`、`UNIQUE` 或 `MULTIPLE`。

## 範例
輸入：
```
4 3
1 2
2 3
3 4
```
輸出：
```
UNIQUE
```

## 這題在練什麼
Kahn 演算法每一步如果同時有兩個以上入度為 0 的點可以選，順序就不唯一；但要先確認整張圖沒有環。
