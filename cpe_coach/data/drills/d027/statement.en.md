# d027 Decimal to Binary

**Stage 0 · Difficulty ★ · Topic: Number bases**

Convert a non-negative integer to its binary representation (without any prefix). The binary representation of 0 is `0`.

## Input
One integer per line (≤ 10^18), until EOF.

## Output
One binary string per line.

## Sample Input
```
10
```

## Sample Output
```
1010
```

## Notes
Number bases appear in CPE very often.
