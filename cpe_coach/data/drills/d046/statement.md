# d046 區間和查詢

**階段 2　難度 ★★　主題：前綴和**

給長度 n 的陣列與 q 個查詢，每個查詢 l r（1 起算），輸出 a[l]+…+a[r]。

## 輸入
第一行 n q；第二行 n 個整數；接著 q 行 l r。n, q ≤ 20000，|a| ≤ 10^6。

## 輸出
每個查詢一行。

## 範例
輸入：
```
5 3
1 2 3 4 5
1 5
2 3
5 5
```
輸出：
```
15
5
5
```

## 這題在練什麼
每次查詢都手寫迴圈加總是 O(nq)，在這裡會超時（用內建 sum(a[l-1:r]) 在這個規模勉強過，但 n、q 放大 5 倍就不行——考題通常會放大）。
