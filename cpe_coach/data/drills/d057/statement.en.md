# d057 N-Queens Count

**Stage 2 · Difficulty ★★★ · Topic: Backtracking**

Place n queens on an n×n chessboard so that no two queens share a row, a column or a diagonal. Given n (1 ≤ n ≤ 9), print the number of solutions.

## Input
One n per line, until EOF, at most 9 lines.

## Output
One integer per line.

## Sample Input
```
4
```

## Sample Output
```
2
```

## Notes
The standard example of backtracking. Think about why you must restore the state.
