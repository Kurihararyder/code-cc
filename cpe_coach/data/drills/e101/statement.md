# e101 成績排名

**階段 1　難度 ★★　主題：排序／輸出格式**

第一行 t。每組先給 n，接著 n 行 `姓名 分數`。依分數由高到低、同分依姓名字典序由小到大排序，輸出名次：同分者名次相同，下一個名次要跳號（例如 1,1,3）。
每組先輸出一行 `Case #k:`，再輸出每人一行 `名次 姓名 分數`。**組與組之間輸出一個空行，最後一組後面沒有空行。**

## 輸入
t ≤ 50，n ≤ 100，姓名為不含空白的英文字母，分數為 0–100 的整數。

## 輸出
見題目。

## 範例
輸入：
```
2
3
bob 90
alice 90
carol 80
2
z 0
y 100
```
輸出：
```
Case #1:
1 alice 90
1 bob 90
3 carol 80

Case #2:
1 y 100
2 z 0
```

## 這題在練什麼
把前面學的 I/O 格式、排序、計數組合起來。
