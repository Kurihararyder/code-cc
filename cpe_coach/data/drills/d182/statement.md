# d182 點在多邊形內嗎

**階段 4　難度 ★★★　主題：計算幾何／點與多邊形**

給一個簡單多邊形（頂點依順時針或逆時針順序給出，邊不會互相交叉，也不會自己接觸）與 q 個點，對每個點輸出它在多邊形的 `INSIDE`（內部）、`BOUNDARY`（剛好在邊上，包含頂點）或 `OUTSIDE`（外部）。

## 輸入
第一行 n（3 ≤ n ≤ 1000）；接著 n 行 `x y`；再來一行 q（1 ≤ q ≤ 1000）；接著 q 行 `x y`。所有座標是絕對值 ≤ 10^4 的整數。

## 輸出
每個點一行。

## 範例
輸入：
```
4
0 0
4 0
4 4
0 4
5
2 2
0 0
2 0
5 2
-1 -1
```
輸出：
```
INSIDE
BOUNDARY
BOUNDARY
OUTSIDE
OUTSIDE
```

## 這題在練什麼
先檢查是否在某條邊上（叉積為 0 且在線段範圍內）；否則從點往右射一條射線，數它穿過幾條邊（奇數次在內部）。注意射線剛好經過頂點的處理：用『一端在上、一端不在上』的半開區間規則。
