# d193 Nim 遊戲

**階段 4　難度 ★★　主題：博弈／Nim**

有 t 局遊戲。每局有 n 堆石頭，兩人輪流取，每次選一堆取走至少 1 顆（可以取光），最後一個取走石頭的人獲勝。兩人都用最佳策略，先手必勝輸出 `FIRST`，否則輸出 `SECOND`。

## 輸入
第一行 t（1 ≤ t ≤ 1000）；每局兩行：n（1 ≤ n ≤ 1000）與 n 個非負整數（≤ 10^9）。

## 輸出
每局一行。

## 範例
輸入：
```
3
3
1 2 3
2
3 4
1
5
```
輸出：
```
SECOND
FIRST
FIRST
```

## 這題在練什麼
所有堆大小的 XOR 不為 0 時先手必勝（Bouton 定理）；為 0 時後手必勝。可以自己用小範例窮舉驗證這個結論。
