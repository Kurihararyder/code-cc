# d196 單點修改區間最小值

**階段 4　難度 ★★★★　主題：資料結構／線段樹**

長度 n 的整數陣列，之後有 q 個操作：`1 i v` 把第 i 個數改成 v；`2 l r` 輸出第 l 到第 r 個數中的最小值（1 起算，含兩端）。

## 輸入
第一行 n q（1 ≤ n, q ≤ 5×10^4）；第二行 n 個整數（絕對值 ≤ 10^9）；接著 q 行操作（|v| ≤ 10^9）。

## 輸出
每個 `2` 操作輸出一行。

## 範例
輸入：
```
5 4
5 3 8 1 9
2 1 5
1 4 10
2 1 5
2 3 3
```
輸出：
```
1
3
8
```

## 這題在練什麼
稀疏表（d087）處理不了修改；線段樹把區間最小值存在二元樹的節點上，修改與查詢都是 O(log n)。非遞迴（bottom-up）寫法最短。
