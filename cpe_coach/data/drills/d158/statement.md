# d158 最小生成樹唯一嗎

**階段 3　難度 ★★★　主題：最小生成樹／唯一性**

連通的無向加權圖 n 個點 m 條邊（可能有重邊與自環）。輸出最小生成樹的總權重，以及最小生成樹是否唯一：只有一棵輸出 `UNIQUE`，有多棵權重相同的最小生成樹輸出 `MULTIPLE`。

## 輸入
第一行 n m（1 ≤ n ≤ 10^4，n − 1 ≤ m ≤ 5×10^4，保證連通）；接著 m 行 `u v w`（1 ≤ w ≤ 10^6）。

## 輸出
一行：總權重 UNIQUE 或 MULTIPLE。

## 範例
輸入：
```
4 5
1 2 1
2 3 2
3 4 3
1 4 4
1 3 5
```
輸出：
```
6 UNIQUE
```

## 這題在練什麼
Kruskal 時把『權重相同的一批邊』一起處理：這批裡在批次開始時能連接不同群組的邊數，如果比實際成功合併的邊數多，就代表有替代的選擇。
