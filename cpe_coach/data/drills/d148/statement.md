# d148 二分圖判斷

**階段 3　難度 ★★　主題：圖／二分圖**

無向圖 n 個點 m 條邊。能不能把所有點塗成黑白兩色，使每條邊兩端的顏色都不同？能輸出 `YES`，不能輸出 `NO`。自己連到自己的邊（自環）會讓答案變成 `NO`；圖可能不連通。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），接著 m 行 `u v`（1 ≤ u, v ≤ n，可能有重邊與自環）。

## 輸出
`YES` 或 `NO`。

## 範例
輸入：
```
4 4
1 2
2 3
3 4
4 1
```
輸出：
```
YES
```

## 這題在練什麼
對每個連通塊 BFS 塗色；遇到兩端同色的邊就是奇環。
