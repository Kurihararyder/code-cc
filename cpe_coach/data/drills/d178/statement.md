# d178 模逆元

**階段 3　難度 ★★★　主題：數論／模逆元**

對每組 a m，找出 x（0 ≤ x < m）使得 a·x ≡ 1 (mod m)。如果不存在（a 與 m 不互質），輸出 -1。

## 輸入
每行兩個整數 a m（1 ≤ a ≤ 10^9，2 ≤ m ≤ 10^9），最多 1000 行，讀到 EOF。m 不一定是質數。

## 輸出
每行一個整數。

## 範例
輸入：
```
3 11
```
輸出：
```
4
```

## 這題在練什麼
擴展歐幾里得算法：求出 x、y 使 a·x + m·y = gcd(a, m)；gcd = 1 時 x mod m 就是答案。
