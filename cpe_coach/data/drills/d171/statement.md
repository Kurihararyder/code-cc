# d171 最大的全 1 正方形

**階段 3　難度 ★★★　主題：網格 DP／正方形**

R×C 的 0/1 方陣。找出最大的『全部都是 1』的正方形（邊與格線平行），輸出它的邊長；沒有 1 時輸出 0。

## 輸入
第一行 R C（1 ≤ R, C ≤ 500），接著 R 行，每行 C 個字元（只有 0 和 1，沒有空格）。

## 輸出
一個整數。

## 範例
輸入：
```
4 5
10100
10111
11111
10010
```
輸出：
```
2
```

## 這題在練什麼
dp[i][j] = 以 (i,j) 為右下角的最大正方形邊長 = 1 + min(上, 左, 左上)（該格是 1 時）。
