# d107 Digital Root

**Stage 0 · Difficulty ★ · Topic: Loops, digits**

For each non-negative integer n (decimal, no leading zeros), repeatedly replace it by the sum of its digits until a single digit remains. Print that digit and how many replacements were made (0 if n already has one digit), as `root count`.

## Input
One integer n per line with at most 1000 digits, until EOF.

## Output
`root count` per line.

## Sample Input
```
38
```

## Sample Output
```
2 2
```

## Notes
n can be very long, so treat it as a string.
