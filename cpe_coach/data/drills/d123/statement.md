# d123 時鐘的夾角

**階段 1　難度 ★★　主題：時間／角度**

每行一個 24 小時制的時間 `hh:mm`。把它看成類比時鐘（12 小時制）時，時針與分針之間較小的那個夾角是幾度？輸出到小數點後 1 位。時針每分鐘走 0.5 度、分針每分鐘走 6 度；12:00 時兩針重合。

## 輸入
每行 `hh:mm`（00:00–23:59），讀到 EOF。

## 輸出
每行一個數字，小數點後恰好 1 位（結果一定是 x.0 或 x.5）。

## 範例
輸入：
```
03:00
```
輸出：
```
90.0
```

## 這題在練什麼
先算兩針各自離 12 點的角度，相減取絕對值；若超過 180 度，改取 360 減它。
