# d007 Leap Year

**Stage 0 · Difficulty ★ · Topic: Conditions**

Given a year, decide whether it is a leap year. A year is a leap year if it is divisible by 4 and not divisible by 100, or if it is divisible by 400. Print `yes` or `no`.

## Input
One positive year per line (≤ 10^5), until EOF.

## Output
For each line print yes or no.

## Sample Input
```
2024
```

## Sample Output
```
yes
```

## Notes
Operator precedence of and / or / not.
