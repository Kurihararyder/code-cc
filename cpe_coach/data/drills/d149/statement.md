# d149 這是一棵樹嗎

**階段 3　難度 ★★　主題：圖／樹的判斷**

無向圖 n 個點 m 條邊。它是不是一棵『樹』（連通且沒有環）？是輸出 `YES`，否則輸出 `NO`。n = 1 且 m = 0 的單一點算樹；重邊與自環都算環。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），接著 m 行 `u v`。

## 輸出
`YES` 或 `NO`。

## 範例
輸入：
```
4 3
1 2
2 3
3 4
```
輸出：
```
YES
```

## 這題在練什麼
樹的充要條件：m = n − 1 且連通。可以用並查集：m = n−1 且每條邊都能成功合併。
