# d095 Expression Evaluation

**Stage 4 · Difficulty ★★★★ · Topic: Parsing, recursive descent**

Each line is an expression made of non-negative integers, `+`, `-`, `*`, parentheses and spaces (no unary minus). Evaluate it with the usual precedence (parentheses > multiplication > addition/subtraction, equal levels from left to right) and print the result (it may be very large).

## Input
Each line has length ≤ 1000, until EOF, at most 100 lines.

## Output
One integer per line.

## Sample Input
```
1+2*3
```

## Sample Output
```
7
```

## Notes
After this problem you understand what a 'compiler' does.
