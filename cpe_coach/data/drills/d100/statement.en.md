# d100 Steps of 3n+1

**Stage 0 · Difficulty ★ · Topic: Loops, while**

Start from a positive integer n and repeat: if n is even replace it by n/2, if n is odd replace it by 3n+1, until n becomes 1. For every n print the number of steps needed (0 steps when n = 1). The numbers on the way may exceed 32-bit integers.

## Input
One integer n per line (1 ≤ n ≤ 10^6), until EOF, at most 1000 lines.

## Output
One integer per line.

## Sample Input
```
6
```

## Sample Output
```
8
```

## Notes
The standard while-loop exercise: condition, update, counter.
