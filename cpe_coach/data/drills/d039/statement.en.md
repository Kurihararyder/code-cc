# d039 Roman Numerals

**Stage 1 · Difficulty ★ · Topic: Strings, mapping**

Convert an integer from 1 to 3999 to a Roman numeral (I V X L C D M; 4=IV, 9=IX, 40=XL, 90=XC, 400=CD, 900=CM).

## Input
One integer per line, until EOF.

## Output
One Roman numeral per line.

## Sample Input
```
4
```

## Sample Output
```
IV
```

## Notes
A lookup table plus a greedy loop.
