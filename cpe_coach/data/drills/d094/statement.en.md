# d094 Digit DP

**Stage 4 · Difficulty ★★★★ · Topic: Digit DP**

Each line contains `N S`: count how many numbers in 1..N have a digit sum of exactly S.

## Input
N ≤ 10^18, S ≤ 162, at most 100 lines, until EOF.

## Output
One integer per line.

## Sample Input
```
100 1
```

## Sample Output
```
3
```

## Notes
Enumerating is impossible at N=10^18. This problem is far from typical CPE and is an advanced optional exercise.
