# d135 火車調度

**階段 2　難度 ★★★　主題：stack／模擬**

n 節車廂依編號 1, 2, …, n 的順序開進一條死巷（只有一個出入口，後進先出）。每次可以把下一節車廂開進去，或把巷子裡最外面（最後進去）的車廂開出來。給定一個『開出的順序』，問是否能做到。有 t 組測資。

## 輸入
第一行 t（1 ≤ t ≤ 100）；每組兩行：第一行 n（1 ≤ n ≤ 10^5），第二行是 1..n 的一個排列（開出的順序）。所有組的 n 總和 ≤ 2×10^5。

## 輸出
每組輸出 `YES` 或 `NO`。

## 範例
輸入：
```
3
5
5 4 3 2 1
5
1 2 3 4 5
5
3 1 2 4 5
```
輸出：
```
YES
YES
NO
```

## 這題在練什麼
模擬：想要輸出 x，就把還沒進去的車廂依序推進去直到 x 進入，再看最外面是不是 x。
