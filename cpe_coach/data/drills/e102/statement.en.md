# e102 Password Strength

**Stage 1 · Difficulty ★ · Topic: Strings**

Score every password (one per line, no whitespace, length 1–50): one point for each satisfied rule: ① length ≥ 8 ② contains a lowercase letter ③ contains an uppercase letter ④ contains a digit ⑤ contains one of `!@#$%^&*`. Print `score level`: 5 points is STRONG; 3 or 4 points is MEDIUM; otherwise WEAK.

## Input
Read until EOF.

## Output
One result per line.

## Sample Input
```
Passw0rd!
```

## Sample Output
```
5 STRONG
```

## Notes
Every rule needs a test case covering it.
