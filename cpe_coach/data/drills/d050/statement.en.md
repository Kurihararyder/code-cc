# d050 Bracket Matching

**Stage 2 · Difficulty ★ · Topic: stack**

Each line is a string containing only `()[]{}`. Decide whether the brackets are properly matched. Print `YES` or `NO`. An empty line counts as valid (YES).

## Input
Each line has length ≤ 10^5, until EOF.

## Output
One line per input line: YES or NO.

## Sample Input
```
([]{})
```

## Sample Output
```
YES
```

## Notes
The first lesson on stacks: when you meet a closing bracket the stack may be empty.
