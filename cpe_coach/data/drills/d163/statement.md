# d163 完全背包

**階段 3　難度 ★★★　主題：背包／完全背包**

n 種物品，第 i 種重量 wᵢ、價值 vᵢ，每種都有『無限多個』。背包容量 W，求能裝進背包（總重量不超過 W）的最大總價值。

## 輸入
第一行 n W（1 ≤ n ≤ 100，0 ≤ W ≤ 10^4）；接著 n 行 `w v`（1 ≤ w ≤ 10^4，1 ≤ v ≤ 10^9）。

## 輸出
一個整數。

## 範例
輸入：
```
2 10
3 5
4 7
```
輸出：
```
17
```

## 這題在練什麼
和 0/1 背包的程式只差內層迴圈的方向：完全背包由小到大（同一物品可以重複用）。
