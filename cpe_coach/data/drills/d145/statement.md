# d145 子集合列舉

**階段 2　難度 ★★　主題：位元運算／子集合**

輸入 n，依『位元遮罩由小到大』輸出 {1,2,…,n} 的所有子集合：遮罩 m 的第 i−1 位（從最低位算起）是 1，代表元素 i 在子集合裡。每個子集合一行，寫成 `{a,b,c}`（元素由小到大，逗號後沒有空格），空集合寫成 `{}`。

## 輸入
一個整數 n（0 ≤ n ≤ 10）。

## 輸出
2ⁿ 行。

## 範例
輸入：
```
3
```
輸出：
```
{}
{1}
{2}
{1,2}
{3}
{1,3}
{2,3}
{1,2,3}
```

## 這題在練什麼
`for m in range(1 << n)`，再用 `m >> i & 1` 判斷第 i 位。
