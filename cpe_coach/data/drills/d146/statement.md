# d146 島嶼數量

**階段 3　難度 ★★　主題：DFS／BFS 連通區域**

R×C 的地圖，`1` 是陸地、`0` 是海。上下左右相鄰的陸地屬於同一座島（斜角不算相連）。輸出島嶼的數量。

## 輸入
第一行 R C（1 ≤ R, C ≤ 500），接著 R 行，每行 C 個字元（只有 0 和 1，沒有空格）。

## 輸出
一個整數。

## 範例
輸入：
```
4 5
11000
11000
00100
00011
```
輸出：
```
3
```

## 這題在練什麼
掃描每個格子：遇到沒走過的陸地就算一座新島，並用 BFS（或迭代的 DFS）把整座島標記起來。遞迴 DFS 在 250000 格的長條島上會爆掉。
