# d031 Until 0 0

**Stage 1 · Difficulty ★ · Topic: Input format**

Each line contains two integers a and b; print |a-b|. Stop when you see `0 0` (do not process that line). Ignore everything after the terminating line.

## Input
|a|, |b| ≤ 10^9.

## Output
One answer per line.

## Sample Input
```
3 5
0 0
```

## Sample Output
```
2
```

## Notes
Many UVA problems end with `0 0` or a single `0`, and there may still be data after the terminating line.
