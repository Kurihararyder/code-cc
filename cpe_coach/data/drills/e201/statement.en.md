# e201 Minimum Gap

**Stage 2 · Difficulty ★★ · Topic: Sorting**

Given n integers (duplicates allowed), look at the differences between adjacent numbers after sorting. Print the smallest difference and the number of adjacent pairs whose difference equals this minimum.

## Input
The first line contains n (2 ≤ n ≤ 30000); the second line contains n integers.

## Output
One line: minimum-difference pair-count.

## Sample Input
```
5
1 5 3 9 11
```

## Sample Output
```
2 3
```

## Notes
'Sort first' makes many problems easy.
