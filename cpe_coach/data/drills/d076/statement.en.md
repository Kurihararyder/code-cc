# d076 Longest Common Subsequence (Large)

**Stage 4 · Difficulty ★★★ · Topic: DP, performance**

The same as d070, but both strings have length up to 3000.

## Input
Two lines of lowercase English letters.

## Output
One integer.

## Sample Input
```
abcde
ace
```

## Sample Output
```
3
```

## Notes
Your first experience of 'the same algorithm, 50 times slower depending on the language'.
