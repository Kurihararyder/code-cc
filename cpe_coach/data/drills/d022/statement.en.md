# d022 GCD and LCM

**Stage 0 · Difficulty ★ · Topic: Math, functions**

For each pair of positive integers a and b, print their gcd and their lcm separated by a space.

## Input
Each line has two integers (≤ 10^9), until EOF.

## Output
One line per pair: gcd lcm.

## Sample Input
```
12 18
```

## Sample Output
```
6 36
```

## Notes
Defining functions with def; the Euclidean algorithm.
