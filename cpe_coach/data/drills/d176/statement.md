# d176 漢米爾頓路徑數

**階段 3　難度 ★★★　主題：位元遮罩 DP／路徑計數**

有向圖 n 個點（n ≤ 15）、m 條邊（沒有重複的邊，也沒有自環）。數有幾條『從點 1 出發、每個點恰好經過一次』的路徑（終點可以是任何點；n = 1 時只有一條）。答案對 1000000007 取餘數。

## 輸入
第一行 n m（1 ≤ n ≤ 15，0 ≤ m ≤ n(n−1)）；接著 m 行 `u v`。

## 輸出
一個整數。

## 範例
輸入：
```
4 5
1 2
2 3
3 4
1 3
2 4
```
輸出：
```
1
```

## 這題在練什麼
dp[mask][v] = 走過 mask 這些點、目前在 v 的路徑數；轉移是再走一條邊到沒走過的點。狀態 2^n × n，轉移 n，n = 15 時約 7×10^6。
