# d090 Maximum Flow (Optional)

**Stage 4 · Difficulty ★★★★ · Topic: Network flow**

A directed graph has n nodes and m edges, each with a capacity. Find the maximum flow from node 1 (source) to node n (sink).

## Input
The first line contains n and m (n ≤ 50, m ≤ 300); then m lines `u v c` (c ≤ 1000). Multiple edges may occur.

## Output
One integer.

## Sample Input
```
4 5
1 2 3
1 3 2
2 3 1
2 4 2
3 4 3
```

## Sample Output
```
5
```

## Notes
Optional problem.
