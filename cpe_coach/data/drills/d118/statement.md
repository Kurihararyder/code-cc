# d118 孿生質數對

**階段 1　難度 ★★　主題：質數／預處理**

孿生質數是相差 2 的兩個質數 (p, p+2)。對每個查詢 n，輸出滿足 p + 2 ≤ n 的孿生質數對有幾組（例如 n = 13 時有 (3,5)、(5,7)、(11,13) 共 3 組）。

## 輸入
第一行 q（1 ≤ q ≤ 10^5），接下來 q 行各一個 n（1 ≤ n ≤ 10^6）。

## 輸出
每個查詢一行。

## 範例
輸入：
```
3
13
5
100
```
輸出：
```
3
1
8
```

## 這題在練什麼
和『質數個數查詢』一樣：預處理一次、之後 O(1) 回答。這次要累計的是『孿生對』的個數。
