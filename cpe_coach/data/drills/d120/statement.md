# d120 字母方陣找單字

**階段 1　難度 ★★　主題：網格掃描／八方向**

第一行 r c，接著 r 行各 c 個小寫字母，最後一行是單字 w（長度 2 以上）。數有幾組『起點格 + 方向』能依序讀出 w：八個方向（上下左右與四個斜向）都可以，讀的過程不能超出方陣。起點相同但方向不同算不同組；單字是回文時，正反兩個方向各算一組。

## 輸入
1 ≤ r, c ≤ 50，2 ≤ |w| ≤ 50。

## 輸出
一個整數。

## 範例
輸入：
```
3 4
abca
bcab
cabc
abc
```
輸出：
```
4
```

## 這題在練什麼
對每個格子、每個方向各檢查一次；提早在第一個不符或超出邊界時停止。
