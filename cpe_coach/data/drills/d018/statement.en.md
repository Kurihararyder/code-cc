# d018 Sorting

**Stage 0 · Difficulty ★ · Topic: Lists, sorting**

Given n integers, print them in ascending order, separated by spaces.

## Input
The first line contains n (≤ 10^5); the second line contains n integers.

## Output
One line.

## Sample Input
```
5
3 1 4 1 5
```

## Sample Output
```
1 1 3 4 5
```

## Notes
sorted() and print(*list).
