# d058 Subset Sum Count

**Stage 2 · Difficulty ★★ · Topic: Enumeration, bit operations**

Given n positive integers (duplicates allowed) and a target T, count the 'index subsets' whose sum is exactly T (the empty set has sum 0).

## Input
The first line contains n and T; the second line contains n integers. n ≤ 18, each number ≤ 1000.

## Output
One integer.

## Sample Input
```
3 3
1 2 3
```

## Sample Output
```
2
```

## Notes
With n ≤ 20 you should think of enumerating all subsets.
