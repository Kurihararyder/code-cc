# d026 Matrix Transpose

**Stage 0 · Difficulty ★ · Topic: 2D lists**

The first line contains r and c; the next r lines each contain c integers. Print the transposed matrix (c rows, r columns), numbers separated by spaces.

## Input
1 ≤ r, c ≤ 100.

## Output
c lines.

## Sample Input
```
2 3
1 2 3
4 5 6
```

## Sample Output
```
1 4
2 5
3 6
```

## Notes
Indexing and building 2D lists.
