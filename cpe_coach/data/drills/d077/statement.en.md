# d077 Prime Count (Large)

**Stage 4 · Difficulty ★★ · Topic: Sieve, performance**

Given N, print the number of primes in 1..N.

## Input
One N per line (≤ 3×10^7), at most 3 lines, until EOF.

## Output
One integer per line.

## Sample Input
```
10
```

## Sample Output
```
4
```

## Notes
Estimate memory too: 3×10^7 booleans take about 30 MB (as chars) or 4 MB (as a bitset).
