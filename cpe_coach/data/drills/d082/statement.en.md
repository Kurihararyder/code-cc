# d082 Polygon Area

**Stage 4 · Difficulty ★ · Topic: Computational geometry**

Given a simple polygon (vertices listed clockwise or counter-clockwise), print twice its area (an integer).

## Input
The first line contains n (3 ≤ n ≤ 10^5); then n lines `x y` (|x|, |y| ≤ 10^6).

## Output
One integer.

## Sample Input
```
4
0 0
2 0
2 2
0 2
```

## Sample Output
```
8
```

## Notes
In geometry problems, use integers instead of floating point whenever you can.
