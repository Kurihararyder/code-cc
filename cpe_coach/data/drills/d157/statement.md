# d157 最小生成森林

**階段 3　難度 ★★　主題：最小生成樹／森林**

無向加權圖 n 個點 m 條邊，圖可能不連通。對每個連通塊都選出最小生成樹，合起來叫最小生成森林。輸出森林的總權重以及連通塊的個數。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），接著 m 行 `u v w`（1 ≤ w ≤ 10^6，可能有重邊與自環）。

## 輸出
一行：總權重 連通塊數。

## 範例
輸入：
```
4 3
1 2 1
2 3 2
1 3 3
```
輸出：
```
3 2
```

## 這題在練什麼
Kruskal 本來就不要求連通：成功合併的邊就是森林的邊，最後的組數就是連通塊數。
