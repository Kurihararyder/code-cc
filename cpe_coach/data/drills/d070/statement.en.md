# d070 Longest Common Subsequence

**Stage 3 · Difficulty ★★★ · Topic: DP (2D)**

Given two strings of lowercase English letters (length ≤ 1000), find the length of their longest common subsequence.

## Input
Two lines, one string each.

## Output
One integer.

## Sample Input
```
abcde
ace
```

## Sample Output
```
3
```

## Notes
A 2D DP can reduce its space to one dimension with a rolling array.
