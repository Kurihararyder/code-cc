# d080 凸包

**階段 4　難度 ★★★★　主題：計算幾何**

平面上 n 個整數座標點（可能重複、共線）。輸出凸包的頂點數（共線的點不算頂點），以及凸包面積的兩倍（整數）。若所有點共線，頂點數輸出 2（只有兩端點）、面積 0；只有一個相異點則頂點數 1、面積 0。

## 輸入
第一行 n（≤ 20000），接著 n 行 `x y`（|x|,|y| ≤ 10^6）。

## 輸出
一行：頂點數 面積兩倍。

## 範例
輸入：
```
4
0 0
1 0
1 1
0 1
```
輸出：
```
4 2
```

## 這題在練什麼
叉積符號與『共線要不要保留』是幾何題最常見的細節。
