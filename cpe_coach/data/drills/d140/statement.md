# d140 最小總等待時間

**階段 2　難度 ★★　主題：貪心／排序**

一台機器依序處理 n 個工作，第 i 個工作需要 tᵢ 單位時間，一次只能做一個，中間不能中斷。一個工作的『等待時間』是它開始前已經過的時間（第一個工作等待 0）。安排順序使所有工作等待時間的總和最小，輸出這個最小總和。

## 輸入
第一行 n（1 ≤ n ≤ 10^5），第二行 n 個整數（1 ≤ tᵢ ≤ 10^4）。

## 輸出
一個整數。

## 範例
輸入：
```
4
3 1 4 2
```
輸出：
```
10
```

## 這題在練什麼
交換論證：把短的工作排前面，它的時間會被後面的每一個工作『等待』更少次。
