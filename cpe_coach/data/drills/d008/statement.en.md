# d008 Grade

**Stage 0 · Difficulty ★ · Topic: Conditions**

A score from 0 to 100 gives a grade: 90 or more is A, 80–89 is B, 70–79 is C, 60–69 is D, anything else is F. Print the grade.

## Input
One integer score per line, until EOF.

## Output
One letter per line.

## Sample Input
```
95
```

## Sample Output
```
A
```

## Notes
elif chains and testing boundary values.
