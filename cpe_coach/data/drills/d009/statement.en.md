# d009 Sum from 1 to n

**Stage 0 · Difficulty ★ · Topic: Loops**

Given n, print 1+2+…+n. Write it with a loop first.

## Input
One positive integer n per line (≤ 10^5), until EOF.

## Output
One answer per line.

## Sample Input
```
10
```

## Sample Output
```
55
```

## Notes
The right end of range() is exclusive. Afterwards, think about whether there is a formula.
