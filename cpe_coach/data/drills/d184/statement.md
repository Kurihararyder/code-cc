# d184 兩圓的關係

**階段 4　難度 ★★★　主題：計算幾何／圓**

每行六個整數 `x1 y1 r1 x2 y2 r2`，是平面上兩個圓（圓心與半徑）。輸出它們的關係：`SAME`（完全重合）、`SEPARATE`（相離，沒有公共點且互相在對方外面）、`EXTERNAL`（外切，恰好一個公共點且互相在對方外面）、`INTERSECT`（相交於兩點）、`INTERNAL`（內切，恰好一個公共點且其中一個在另一個裡面）、`CONTAIN`（內含，沒有公共點且其中一個在另一個裡面）。

## 輸入
座標絕對值 ≤ 10^9，半徑 1 ≤ r ≤ 10^9，讀到 EOF，最多 1000 行。

## 輸出
每行一個單字。

## 範例
輸入：
```
0 0 3 5 0 3
```
輸出：
```
INTERSECT
```

## 這題在練什麼
用『圓心距離的平方』和 (r1+r2)²、(r1−r2)² 比較，全部是整數運算，不要用 sqrt 與浮點數（座標 10^9 時浮點數會算錯）。
