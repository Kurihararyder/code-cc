# d190 前綴相似度總和

**階段 4　難度 ★★★　主題：字串／Z 函數**

對字串 s 的每個後綴 s[i..]（i 從 0 起，i = 0 是整個 s），計算它和 s 的『最長共同前綴長度』，輸出這些長度的總和。例如 `ababa` 的各後綴共同前綴長度是 5, 0, 3, 0, 1，總和 9。

## 輸入
一行小寫英文字母字串（1 ≤ 長度 ≤ 2×10^5）。

## 輸出
一個整數。

## 範例
輸入：
```
ababa
```
輸出：
```
9
```

## 這題在練什麼
Z 函數：z[i] 就是 s[i..] 與 s 的最長共同前綴；利用已知的最右區間 [l, r] 可以在 O(n) 內算完，暴力比對是 O(n²)。
