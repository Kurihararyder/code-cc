# d040 Day of the Week

**Stage 1 · Difficulty ★ · Topic: Dates**

Given a date `y m d` (years 1900–2100, guaranteed valid), print the day of the week: Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.

## Input
Read until EOF.

## Output
One English weekday name per line.

## Sample Input
```
2024 1 1
```

## Sample Output
```
Monday
```

## Notes
The CPE exam machines run Python 3.9.6; datetime is available.
