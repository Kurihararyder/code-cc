# d128 矩形區域和

**階段 2　難度 ★★★　主題：前綴和／二維**

給 R×C 的整數方格與 q 個詢問，每個詢問 `r1 c1 r2 c2`（列、行都從 1 算起，r1 ≤ r2、c1 ≤ c2），輸出左上角 (r1,c1) 到右下角 (r2,c2) 這個矩形內所有數字的總和。

## 輸入
第一行 R C q（1 ≤ R, C ≤ 500，1 ≤ q ≤ 10^5）；接著 R 行各 C 個整數（絕對值 ≤ 1000）；再接著 q 行詢問。

## 輸出
每個詢問一行。

## 範例
輸入：
```
3 3 2
1 2 3
4 5 6
7 8 9
1 1 3 3
2 2 3 3
```
輸出：
```
45
28
```

## 這題在練什麼
二維前綴和：`S[i][j] = a[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]`，詢問用『大減小再補回重疊』的容斥。
