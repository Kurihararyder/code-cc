# d127 會議室數量

**階段 2　難度 ★★　主題：heap／掃描線**

有 n 場會議，第 i 場從時間 sᵢ 開始、到 eᵢ 結束（sᵢ < eᵢ）。一間會議室同一時間只能開一場會；一場會結束的那一刻會議室就空出來，所以 eᵢ 等於另一場的 sⱼ 時可以共用。最少需要幾間會議室？

## 輸入
第一行 n（1 ≤ n ≤ 10^5）；接著 n 行 `s e`（0 ≤ s < e ≤ 10^9）。

## 輸出
一個整數。

## 範例
輸入：
```
3
0 30
5 10
15 20
```
輸出：
```
2
```

## 這題在練什麼
按開始時間排序；用最小堆放『正在使用的會議室的結束時間』：新會議開始時，堆頂結束時間 ≤ 開始時間就重用（pop），最後堆的大小就是答案。
