# e303 Split Into Two Piles

**Stage 3 · Difficulty ★★★ · Topic: Knapsack**

Split n positive integers into two piles (every number belongs to exactly one pile) so that the absolute difference of the pile sums is as small as possible. Print that minimum difference.

## Input
The first line contains n (≤ 100); the second line contains n integers (each ≤ 100).

## Output
One integer.

## Sample Input
```
4
1 6 11 5
```

## Sample Output
```
1
```

## Notes
The same family as d068, but you first have to find the reduction.
