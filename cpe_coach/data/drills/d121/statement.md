# d121 斜線填數

**階段 1　難度 ★　主題：二維陣列／填數**

輸入 n，輸出 n×n 的方陣，把 1 到 n² 沿著『斜線』依序填入：先填左上角的 1；接著填第一條斜線（右上到左下方向，也就是由列號小的格子往列號大的格子填）的所有格子，再填下一條，直到右下角。n = 3 的結果為
`1 2 4`
`3 5 7`
`6 8 9`

## 輸入
一個整數 n（1 ≤ n ≤ 50）。

## 輸出
n 行，每行 n 個數字，以空格隔開。

## 範例
輸入：
```
3
```
輸出：
```
1 2 4
3 5 7
6 8 9
```

## 這題在練什麼
同一條斜線上的格子，列號加行號是固定值。
