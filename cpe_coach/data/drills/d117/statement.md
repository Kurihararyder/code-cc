# d117 完全數、盈數與虧數

**階段 1　難度 ★★　主題：數學／因數**

一個正整數 n 的『真因數』是 n 的所有正因數但不含 n 自己（1 的真因數總和是 0）。設真因數總和為 s：s = n 輸出 `PERFECT`，s > n 輸出 `ABUNDANT`，s < n 輸出 `DEFICIENT`。

## 輸入
每行一個整數 n（1 ≤ n ≤ 10^6），最多 2000 行，讀到 EOF。

## 輸出
每行一個單字。

## 範例
輸入：
```
28
```
輸出：
```
PERFECT
```

## 這題在練什麼
成對找因數：i 整除 n 時，n // i 也是因數；i 到 √n 就夠了；平方數的 i 與 n // i 相同，只能加一次。
