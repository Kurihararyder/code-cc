# d072 Minimum Path Sum in a Grid

**Stage 3 · Difficulty ★★ · Topic: DP (grid)**

An R×C grid contains a non-negative integer in each cell. Walk from the top-left to the bottom-right corner, moving only right or down. What is the minimum possible sum of the numbers on the path?

## Input
The first line contains R and C (≤ 300); then R lines with C integers each (≤ 1000).

## Output
One integer.

## Sample Input
```
3 3
1 3 1
1 5 1
4 2 1
```

## Sample Output
```
7
```

## Notes
Handling the borders is the point of this problem.
