# d037 Base Conversion

**Stage 1 · Difficulty ★ · Topic: Number bases**

Each line contains three values `s a b`: s is a number written in base a (2 ≤ a ≤ 16; capital letters stand for 10–15). Convert it to base b (2 ≤ b ≤ 16) and print it in capital letters.

## Input
After conversion to decimal, s is ≤ 10^18. The output has no leading zeros (print 0 for zero). Read until EOF.

## Output
One answer per line.

## Sample Input
```
FF 16 2
```

## Sample Output
```
11111111
```

## Notes
Base conversion is very common in past CPE exams.
