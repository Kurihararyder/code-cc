# d069 Longest Increasing Subsequence

**Stage 3 · Difficulty ★★★ · Topic: DP + binary search**

Given an integer sequence of length n, find the length of the longest strictly increasing subsequence (the elements need not be contiguous).

## Input
The first line contains n (≤ 50000); the second line contains n integers.

## Output
One integer.

## Sample Input
```
8
10 9 2 5 3 7 101 18
```

## Sample Output
```
4
```

## Notes
Write the O(n²) version first to understand the dp, then upgrade to O(n log n).
