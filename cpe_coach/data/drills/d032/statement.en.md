# d032 Number of Cases First

**Stage 1 · Difficulty ★ · Topic: Input format**

The first line contains t, the number of test cases. Each case has two lines: the first contains n, the second contains n integers. For each case print the sum.

## Input
t ≤ 100, n ≤ 1000; n may be 0 (then the second line is empty).

## Output
One line per case.

## Sample Input
```
2
3
1 2 3
2
10 -10
```

## Sample Output
```
6
0
```

## Notes
Reading everything and splitting it is safe against blank lines and line-break placement, but it cannot be used when the line structure matters.
