# d191 前綴計數

**階段 4　難度 ★★★　主題：字串／前綴查詢**

給 n 個單字（可能重複，重複的各算一個）與 q 個查詢字串，對每個查詢輸出有幾個單字是以它開頭的（單字本身等於查詢也算）。

## 輸入
第一行 n q（1 ≤ n, q ≤ 5×10^4）；接著 n 行各一個單字、再接著 q 行各一個查詢字串，皆為小寫英文字母；所有單字長度總和與所有查詢長度總和各 ≤ 2×10^5。

## 輸出
每個查詢一行。

## 範例
輸入：
```
4 3
apple
app
apply
banana
app
b
c
```
輸出：
```
3
1
0
```

## 這題在練什麼
把單字排序後，以某前綴開頭的單字是連續的一段，用二分搜尋找出這一段的兩端；或建立字典樹（trie）並在每個節點記錄經過的單字數。
