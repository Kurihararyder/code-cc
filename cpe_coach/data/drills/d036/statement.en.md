# d036 Big Sum and Product

**Stage 1 · Difficulty ★ · Topic: Big integers**

Each line contains two non-negative integers a and b (up to 500 digits). Print a+b and a*b, each on its own line.

## Input
Read until EOF; at most 20 lines.

## Output
Two lines per pair.

## Sample Input
```
1 2
```

## Sample Output
```
3
2
```

## Notes
What C++ cannot do easily, Python does in one line.
