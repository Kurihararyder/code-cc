# d034 Case Format and Blank Lines

**Stage 1 · Difficulty ★ · Topic: Output format**

The first line contains t; then t lines follow, each containing an integer n. For the k-th case print `Case #k:` and on the next line print 1+2+…+n. **Print one blank line between consecutive cases, but none after the last case.**

## Input
t ≤ 100, n ≤ 10^6.

## Output
See the sample.

## Sample Input
```
2
3
4
```

## Sample Output
```
Case #1:
6

Case #2:
10
```

## Notes
Common in UVA: distinguish carefully between a blank line *between* cases and one *after every* case. It is the biggest source of PE (presentation error).
