# d049 Student Ranking

**Stage 2 · Difficulty ★ · Topic: Custom sorting**

There are n students; each line contains `name score`. Sort by score from high to low; for equal scores sort by name in lexicographic order. Print `name score`.

## Input
The first line contains n (≤ 10^5); then n lines. A name consists of English letters without whitespace.

## Output
n lines.

## Sample Input
```
3
bob 90
alice 90
carol 100
```

## Sample Output
```
carol 100
alice 90
bob 90
```

## Notes
The key function of sorting; strings are compared lexicographically.
