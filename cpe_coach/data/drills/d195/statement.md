# d195 動態區間和

**階段 4　難度 ★★★　主題：資料結構／樹狀陣列**

長度 n 的整數陣列，之後有 q 個操作：`1 i v` 把第 i 個數加上 v；`2 l r` 輸出第 l 到第 r 個數的總和（都是 1 起算，含兩端）。

## 輸入
第一行 n q（1 ≤ n, q ≤ 5×10^4）；第二行 n 個整數（絕對值 ≤ 10^9）；接著 q 行操作（|v| ≤ 10^9）。

## 輸出
每個 `2` 操作輸出一行。

## 範例
輸入：
```
5 4
1 2 3 4 5
2 1 5
1 3 10
2 1 3
2 3 3
```
輸出：
```
15
16
13
```

## 這題在練什麼
前綴和不能處理『修改』：每次修改都重算是 O(n)。樹狀陣列（Fenwick tree / BIT）讓修改與查詢都是 O(log n)。
