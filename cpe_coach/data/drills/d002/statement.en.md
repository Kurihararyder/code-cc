# d002 Sums of Many Pairs

**Stage 0 · Difficulty ★ · Topic: Input/Output, EOF**

The input has many lines; each line contains two integers a and b. For every line, print a+b.

## Input
The number of lines is not given: read until end of file (EOF). |a|, |b| ≤ 10^18.

## Output
One answer per line.

## Sample Input
```
1 2
```

## Sample Output
```
3
```

## Notes
The most common input form in contests: read until EOF. Python's int never overflows.
