# d088 負權邊與負環

**階段 4　難度 ★★★★　主題：Bellman-Ford**

有向圖 n 點 m 邊，邊權可為負。若從點 1 出發能到達某個負環，輸出 `NEGATIVE CYCLE`；否則輸出點 1 到點 n 的最短距離，到不了輸出 `UNREACHABLE`。

## 輸入
第一行 n m（n ≤ 500, m ≤ 3000），接著 m 行 `u v w`（|w| ≤ 1000）。

## 輸出
一行。

## 範例
輸入：
```
3 3
1 2 4
2 3 -2
1 3 5
```
輸出：
```
2
```

## 這題在練什麼
『從 1 可達』這個條件容易漏掉：不可達的負環不算。
