# d001 Greeting

**Stage 0 · Difficulty ★ · Topic: Input/Output**

Read one line containing a name and print `Hello, <name>!`.

## Input
One line: the name (English letters, length ≤ 20).

## Output
One line: the greeting.

## Sample Input
```
Alice
```

## Sample Output
```
Hello, Alice!
```

## Notes
input() and print(); string formatting.
