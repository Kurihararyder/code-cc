# d101 Fizz Buzz

**階段 0　難度 ★　主題：迴圈／條件**

輸入 n，輸出 n 行：第 i 行（i 從 1 開始）若 i 同時是 3 和 5 的倍數輸出 `FizzBuzz`，只是 3 的倍數輸出 `Fizz`，只是 5 的倍數輸出 `Buzz`，否則輸出 i 本身。

## 輸入
一個整數 n（1 ≤ n ≤ 100）。

## 輸出
n 行。

## 範例
輸入：
```
15
```
輸出：
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

## 這題在練什麼
先判斷『同時』的情況（15 的倍數），否則會被前面的條件吃掉。
