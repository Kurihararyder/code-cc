# d101 Fizz Buzz

**Stage 0 · Difficulty ★ · Topic: Loops, conditions**

Read n and print n lines: on line i (starting from 1) print `FizzBuzz` if i is a multiple of both 3 and 5, `Fizz` if it is only a multiple of 3, `Buzz` if it is only a multiple of 5, and i itself otherwise.

## Input
One integer n (1 ≤ n ≤ 100).

## Output
n lines.

## Sample Input
```
15
```

## Sample Output
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

## Notes
Test the 'both' case (multiples of 15) first, otherwise an earlier condition swallows it.
