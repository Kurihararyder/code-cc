# d012 Sum of Digits

**Stage 0 · Difficulty ★ · Topic: Loops, digits**

Given a non-negative integer n (< 10^18), print the sum of its decimal digits.

## Input
One integer per line, until EOF.

## Output
One answer per line.

## Sample Input
```
12345
```

## Sample Output
```
15
```

## Notes
A while loop; you can also treat the number as a string (know both ways).
