# d104 Intersection and Union

**Stage 0 · Difficulty ★ · Topic: Set operations**

The input has two lines, each an integer set (digits may repeat; separated by spaces; 1–100 integers per line with absolute value ≤ 1000). On the first output line print the intersection (ascending, space-separated; print `EMPTY` if there is no common element); on the second print the union (ascending).

## Input
Two lines, each an integer set.

## Output
Two lines.

## Sample Input
```
1 2 3 4
3 4 5 6
```

## Sample Output
```
3 4
1 2 3 4 5 6
```

## Notes
The set operators `&` and `|`, then sorted.
