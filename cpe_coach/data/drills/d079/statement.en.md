# d079 Floyd (Large)

**Stage 4 · Difficulty ★★★ · Topic: Shortest paths, performance**

An undirected weighted graph has n ≤ 400 nodes and m edges. Answer q queries `a b` with the shortest distance; print -1 if not connected.

## Input
The first line contains n, m and q; then m lines `u v w` (1 ≤ w ≤ 1000); then q lines of queries.

## Output
q lines.

## Sample Input
```
3 2 2
1 2 4
2 3 5
1 3
3 1
```

## Sample Output
```
9
9
```
