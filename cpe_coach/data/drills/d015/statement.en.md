# d015 Palindrome

**Stage 0 · Difficulty ★ · Topic: Strings**

Decide whether each line is a palindrome (it reads the same forwards and backwards; case-sensitive). Print `YES` or `NO`.

## Input
Each line is a string without whitespace (length 1–1000), until EOF.

## Output
For each line print YES or NO.

## Sample Input
```
level
```

## Sample Output
```
YES
```

## Notes
Reverse the string and compare.
