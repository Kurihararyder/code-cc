# d086 Inversions

**Stage 4 · Difficulty ★★★★ · Topic: Divide and conquer / BIT**

Given n integers, count the pairs i<j with a[i] > a[j].

## Input
The first line contains n (≤ 30000); the second line contains n integers.

## Output
One integer (possibly large).

## Sample Input
```
5
2 4 1 3 5
```

## Sample Output
```
3
```

## Notes
The answer can reach n²/2; in C++ use long long.
