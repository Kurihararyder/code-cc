# d136 資料流的第 k 大

**階段 2　難度 ★★　主題：heap**

數字一個接一個進來。從第 k 個數開始，每進來一個數，就輸出『目前已進來的所有數中第 k 大的值』（有重複時重複的數各算一個，例如 5 5 3 的第 2 大是 5）。

## 輸入
第一行 n k（1 ≤ k ≤ n ≤ 2×10^5）；第二行 n 個整數（絕對值 ≤ 10^9）。

## 輸出
一行 n−k+1 個整數，以空格隔開。

## 範例
輸入：
```
6 3
4 5 8 2 9 1
```
輸出：
```
4 4 5 5
```

## 這題在練什麼
維持一個大小為 k 的最小堆：堆頂就是第 k 大。新數比堆頂大才換掉堆頂。
