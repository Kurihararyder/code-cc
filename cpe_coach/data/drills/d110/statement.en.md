# d110 Rotate a Matrix

**Stage 0 · Difficulty ★★ · Topic: 2D lists, rotation**

The first line has r c, followed by r lines of c integers. Print the matrix rotated 90 degrees clockwise (c lines of r numbers separated by spaces).

## Input
1 ≤ r, c ≤ 100, absolute values ≤ 10^9.

## Output
c lines.

## Sample Input
```
2 3
1 2 3
4 5 6
```

## Sample Output
```
4 1
5 2
6 3
```

## Notes
Line j of the result is column j of the original, read from bottom to top.
