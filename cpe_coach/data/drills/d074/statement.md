# d074 旅行推銷員（小規模）

**階段 3　難度 ★★★★　主題：位元遮罩 DP**

n 個城市（n ≤ 12），給距離矩陣 d[i][j]（可能不對稱）。從城市 0 出發，每個城市恰好拜訪一次，最後回到 0，求最短總距離。n=1 時答案為 0。

## 輸入
第一行 n；接著 n 行各 n 個整數（0 ≤ d ≤ 1000）。

## 輸出
一個整數。

## 範例
輸入：
```
3
0 10 15
10 0 20
15 20 0
```
輸出：
```
45
```

## 這題在練什麼
n ≤ 12~20 通常暗示 bitmask。n=12 在 Python 約 10^7 次運算，要注意常數。
