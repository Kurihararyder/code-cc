# d179 大量質因數分解

**階段 3　難度 ★★★　主題：數論／篩法**

有很多個整數 n，對每個輸出質因數分解（質因數由小到大，格式 `p^e`，以空格隔開，指數是 1 也要寫）。

## 輸入
第一行 q（1 ≤ q ≤ 10^5），接著 q 行各一個整數 n（2 ≤ n ≤ 10^6）。

## 輸出
每個詢問一行。

## 範例
輸入：
```
3
12
97
1000000
```
輸出：
```
2^2 3^1
97^1
2^6 5^6
```

## 這題在練什麼
對每個數各自試除太慢：先用篩法預處理『最小質因數 spf[n]』，之後每個數只要不斷除以 spf 就好。
