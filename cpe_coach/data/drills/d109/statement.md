# d109 掃雷

**階段 0　難度 ★★　主題：二維 list／模擬**

第一行 r c，接著 r 行各 c 個字元：`*` 是地雷，`.` 是空地。輸出同樣大小的盤面：地雷仍然是 `*`，每個空地換成它周圍八格（上下左右與四個斜角）裡的地雷數（0–8 的數字）。

## 輸入
1 ≤ r, c ≤ 100。

## 輸出
r 行，每行 c 個字元。

## 範例
輸入：
```
3 4
*...
....
.*..
```
輸出：
```
*100
2210
1*10
```

## 這題在練什麼
走訪八個方向時要檢查邊界；用方向表 `[(-1,-1),(-1,0),...]` 最不容易寫錯。
