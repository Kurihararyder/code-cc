# d014 Count the Vowels

**Stage 0 · Difficulty ★ · Topic: Strings**

For each line of text, print how many times the letters a, e, i, o, u appear (case-insensitive). **An empty line is still a line**; its answer is 0.

## Input
Each line is a piece of text (it may contain spaces and punctuation), until EOF.

## Output
One integer per line.

## Sample Input
```
Hello World
```

## Sample Output
```
3
```

## Notes
Iterating over a string and the `in` operator; note that an empty line is valid data.
