# d113 Digit Sum of a Factorial

**Stage 1 · Difficulty ★★ · Topic: Big integers**

For each n, compute the sum of the decimal digits of n!.

## Input
One integer n per line (0 ≤ n ≤ 1000), at most 100 lines, until EOF.

## Output
One integer per line.

## Sample Input
```
5
```

## Sample Output
```
3
```

## Notes
1000! has 2568 digits and cannot fit in a C++ long long, but a Python int handles it directly.
