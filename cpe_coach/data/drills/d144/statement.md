# d144 1 到 n 的位元 1 總數

**階段 2　難度 ★★★　主題：位元運算／數學**

對每個 n，求 1, 2, …, n 這 n 個數的二進位表示裡，所有「1」的個數總和（例如 n = 3：1=1、2=10、3=11，共 4 個）。

## 輸入
每行一個整數 n（1 ≤ n ≤ 10^18），最多 1000 行，讀到 EOF。

## 輸出
每行一個整數。

## 範例
輸入：
```
3
```
輸出：
```
4
```

## 這題在練什麼
逐位看：第 i 位（從 0 起）的 1 每 2^(i+1) 個數出現一段、每段長 2^i——用『完整週期數 × 2^i 加上最後不完整的部分』計算。
