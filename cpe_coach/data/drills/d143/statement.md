# d143 質數環

**階段 2　難度 ★★★　主題：回溯／剪枝**

把 1 到 n 這 n 個數排成一個圓環（n = 1 時只有一個數，它和自己相鄰、和是 2 是質數，答案是 1；n ≥ 3 的奇數答案是 0），要求圓環上每相鄰兩數（包括最後一個和第一個）的和都是質數。固定 1 放在第一個位置，數有幾種排法（順時針與逆時針的鏡像算不同的排法）。

## 輸入
每行一個整數 n（1 ≤ n ≤ 14），最多 14 行，讀到 EOF。

## 輸出
每行一個整數。

## 範例
輸入：
```
4
```
輸出：
```
2
```

## 這題在練什麼
逐個位置放數字，放不下就立刻回頭（剪枝）：新放的數必須和前一個的和是質數，最後還要檢查和 1 的和。
