# d141 河內塔

**階段 2　難度 ★★　主題：遞迴**

n 個大小不同的圓盤由小到大疊在 A 柱上（小的在上），要全部移到 C 柱，每次只能移一個，且大盤不能壓在小盤上，B 柱可以暫放。輸出最少移動次數，以及每一步移動的『從哪根柱子 到哪根柱子』，格式 `X Y`（最少步數的走法是唯一的）。

## 輸入
一個整數 n（1 ≤ n ≤ 10）。

## 輸出
第一行是最少步數 m（= 2ⁿ − 1），接著 m 行各一步，例如 `A C`。

## 範例
輸入：
```
3
```
輸出：
```
7
A C
A B
C B
A C
B A
B C
A C
```

## 這題在練什麼
遞迴想法：先把上面 n−1 個移到 B，再移最大的到 C，最後把 n−1 個從 B 移到 C。
