# d152 最少學期數

**階段 3　難度 ★★　主題：拓撲排序／分層**

n 門課，m 個先修限制 `a b` 表示 a 要在 b 之前修完（不能同一學期）。每學期可以修任意多門『先修課都已經在之前的學期修完』的課。最少要幾個學期才能修完全部？如果先修限制有環（永遠修不完；自己是自己的先修也算環）輸出 -1。

## 輸入
第一行 n m（1 ≤ n ≤ 10^5，0 ≤ m ≤ 2×10^5），接著 m 行 `a b`（可能有重複的限制）。

## 輸出
一個整數。

## 範例
輸入：
```
4 3
1 2
2 3
1 4
```
輸出：
```
3
```

## 這題在練什麼
答案就是 DAG 上『最長路徑的點數』；Kahn 演算法一層一層處理就是在數學期。
