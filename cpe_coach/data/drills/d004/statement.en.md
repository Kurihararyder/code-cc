# d004 Celsius to Fahrenheit

**Stage 0 · Difficulty ★ · Topic: Arithmetic, formatting**

For each temperature C (an integer) in degrees Celsius, print the temperature in Fahrenheit F = C×9/5+32 with exactly one digit after the decimal point.

## Input
One integer C per line (-100 ≤ C ≤ 100), until EOF.

## Output
One answer per line.

## Sample Input
```
0
```

## Sample Output
```
32.0
```

## Notes
Output formatting with `:.1f`.
