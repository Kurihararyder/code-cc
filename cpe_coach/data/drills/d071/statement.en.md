# d071 Maximum Subarray Sum

**Stage 3 · Difficulty ★★ · Topic: DP (Kadane)**

Given n integers (possibly negative), find the maximum sum of a non-empty contiguous subarray.

## Input
The first line contains n (≤ 50000); the second line contains n integers.

## Output
One integer.

## Sample Input
```
9
-2 1 -3 4 -1 2 1 -5 4
```

## Sample Output
```
6
```

## Notes
The initial value and the 'all negative' case are what this problem tests.
