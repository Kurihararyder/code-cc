# d033 Blank-Line-Separated Groups

**Stage 1 · Difficulty ★ · Topic: Input format**

The input consists of several groups separated by **one blank line**. Each group has some lines, each containing one integer. For each group print the sum of its integers.

## Input
At most 100 groups, at most 100 lines per group. There is no extra blank line at the end of the input.

## Output
One line per group.

## Sample Input
```
1
2
3

10
20
```

## Sample Output
```
6
30
```

## Notes
UVA 10226 and 10282 use this format. Forgetting the last group at EOF is a classic bug.
