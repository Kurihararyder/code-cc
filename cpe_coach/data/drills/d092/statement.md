# d092 取石子遊戲

**階段 4　難度 ★★★　主題：博弈 DP**

一堆 n 顆石頭，兩人輪流取，每次可取的數量必須是給定集合 S 中的某個數（取不夠的數量不能選），不能取的人輸。先手必勝輸出 `WIN`，否則 `LOSE`。

## 輸入
第一行 k q（k ≤ 10, q ≤ 1000）；第二行 k 個正整數 S；接著 q 行每行一個 n（0 ≤ n ≤ 10^6）。

## 輸出
每個查詢一行。

## 範例
輸入：
```
3 5
1 3 4
0 1 2 3 7
```
輸出：
```
LOSE
WIN
LOSE
WIN
LOSE
```

## 這題在練什麼
觀察週期也是一種解法。
