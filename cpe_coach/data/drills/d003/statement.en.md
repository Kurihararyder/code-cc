# d003 Rectangle

**Stage 0 · Difficulty ★ · Topic: Arithmetic**

Given the length w and the width h of a rectangle, print its area and its perimeter separated by one space.

## Input
One line with two positive integers w and h (≤ 10^6).

## Output
One line: area perimeter.

## Sample Input
```
3 4
```

## Sample Output
```
12 14
```

## Notes
map(), multiple assignment, printing several values separated by spaces.
