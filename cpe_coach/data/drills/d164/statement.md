# d164 恰好裝滿的背包

**階段 3　難度 ★★★　主題：背包／恰好裝滿**

n 個物品（每個最多選一次），第 i 個重量 wᵢ、價值 vᵢ。選出一些物品使總重量『恰好等於』W，求最大總價值；如果無法恰好裝滿輸出 -1。

## 輸入
第一行 n W（1 ≤ n ≤ 100，0 ≤ W ≤ 10^4）；接著 n 行 `w v`（1 ≤ w ≤ 10^4，1 ≤ v ≤ 10^9）。

## 輸出
一個整數。

## 範例
輸入：
```
3 5
2 3
3 4
4 10
```
輸出：
```
7
```

## 這題在練什麼
和一般背包的差別在初值：dp[0] = 0，其餘設成 −∞（代表『還湊不出這個重量』）。
